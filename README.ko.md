# POSIM-SLAM

`delayed_surface_update`는 상태 블록을 순서대로 제거해 상관관계가 있는 지연 거리
관측을 준비합니다. 과거 자세를 확정값으로 고정하지 않고 조건부 관계와 현재 상태의
불확실성을 유지합니다. 선택형 네이티브 `SurfaceMarginalOwner`는 새 현재 상태 제약,
조건부 관계와 원본 관측 기록을 함께 설치합니다. 활성 IMU·DVL·압력 제약은 각자의
관측을 유지하며, 미지 평면은 최적화와 상태 주변화를 거쳐 보존합니다.
`native_surface.prepare_native_ranges`는 네이티브 상태 사본에서 새 제약만 준비하고,
`LiveClient`는 이를 추정기 스레드의 큐로 전달합니다. 네이티브 소유자는 상태 사본의
식별자, 원본 관측의 중복 사용과 명시적인 기록 만료를 검사합니다. 이 선택 기능의
기본값은 꺼짐이며, 실제 반사면 대응·불확실성 보정·유용한 소나 지도 검증이 필요합니다.
[스트리밍 API와 원본 재생 검사](docs/diagnostics/native-surface-transport-20261029/README.md),
[네이티브 소유자 API](docs/diagnostics/native-surface-owner-20261029/README.md),
[참조 계산 방법](docs/diagnostics/delayed-surface-update-20261029/README.md).

`native_surface_ranges`는 네이티브 소유 좌표에서 원본 원뿔·팬 거리 제약을
함께 계산합니다. 실제 상관된 거리 제약으로 새 미지 평면을 초기화한 뒤,
전체 지지 범위를 다시 확인하고 갱신을 준비합니다. 지지 확인용 거리 표본은
추가 확률 정보를 만들지 않습니다. 읽기 전용 검사는 평면의 관측 불가능한
방향을 보존하고 비선형 거리식을 다시 평가합니다.
[원본 초기화 검사와 거부된 대응](docs/diagnostics/native-surface-ranges-20261029/README.md).

`NativeSurfaceSnapshot.joint_marginal`은 같은 네이티브 소유자의 수치 감쇠 없는
정보를 읽고, 공유된 과거 상태의 조건부 관계에 현재 상태의 불확실성을 전파합니다.
Householder QR과 유효 정보 방향을 구분하는 SVD로 자세·평면·압력 기준값의 상관관계와
관측 불가능한 방향을 유지합니다. 강건 가중치와 지정된 센서 잡음에 따른 국소 근사입니다.
[결합 불확실성과 원본 입력 검사](docs/diagnostics/native-surface-information-20261029/README.md).

선택형 네이티브 표면 추정기는 첫 IMU 상태에 `InitialImuBiasCalibration`을
적용합니다. 전체 공분산의 유한 분산 방향은 사전 제약으로, 분산 0인 방향은 정확한
등식으로 처리하며 최적화·주변화·지연 갱신에서도 유지합니다. IMU 잡음과 이후의
바이어스 랜덤워크는 별도로 유지합니다. 일치하는 워커의 보정 적용 확인이 필요합니다.
[보정 입력·원본 재생·한계](docs/diagnostics/native-imu-bias-calibration-20261029/README.md).

[벽·모서리 관측 대조](docs/diagnostics/sonar-wall-corner-20261030/README.md)에 한 주행 기록의 전체 항법·음향 출력과 같은 시각의 RGB·소나, 동일 투영의 현장·점군 비교를 보존합니다.

[소나 입력 진단](docs/diagnostics/sonar-pr31-36-20261030/README.ko.md)은 빈 영상 복구, 최대 거리 격자와 Orca5 지형의 시각이 맞는 RGB·소나를 검사합니다. 저장한 복소 연산 출력은 독립 NumPy 검사기로 확인합니다.

[검사 장면의 점 복원 대조](docs/diagnostics/sonar-inspection-scene-20261031/README.ko.md)에 #31–36 통합을 적용한 전체 점군, 같은 방향의 네이티브 RGB, 정확한 자세 대조군을 보존합니다. 유용한 점 지도는 아직 검증되지 않았습니다.

[고도 호 대응과 관측 동작 검토](docs/diagnostics/sonar-return-support-20261031/README.ko.md)는 같은 검출 특징의 기술자·고도 전체 탐색을 비교하며 모든 조건부 점과 미해결 관측성을 보존합니다.

[근거리 관측 검토](docs/diagnostics/sonar-close-view-20261031/README.ko.md)는 실제 표적의 가시성과 특징 대응의 지속성을 구분하고, 미합격 네이티브·오프라인 지도를 전체 보존합니다.

[조건부 그림자 기하](docs/diagnostics/sonar-shadow-support-20261031/README.ko.md)는 각도·물리 평면 배경을 비교하며 모든 관측 가설과 미해결 평면·자세 불확실성을 보존합니다.

[알려진 평면의 DVL 보정](docs/diagnostics/dvl-plane-calibration-20261031/README.ko.md)은 조건부 반사 방향 평균과 미확정 거리 불확실성을 구분하고 정적 관측 모델 대조군을 전체 보존합니다.

[병진 시점 대조](docs/diagnostics/sonar-translated-view-20261031/README.ko.md)는 실제 62.87° 관측 시점 변화, 시각이 맞는 센서와 실패 지도의 모든 점을 보존합니다. 넓은 동작만으로 기존 점 모델은 합격하지 못합니다.

[병진 시점의 그림자 관측](docs/diagnostics/sonar-translated-shadow-20261031/README.ko.md)은 모든 조건부 영역 관측과 실제 모서리·평균 영상 대조를 보존합니다. 강도 영상 경계만으로 대응하는 물리적 모서리를 확인할 수 없습니다.

`sonar_input`은 전력 0인 `-inf` 표본을 보존하고 대역폭·음속으로 광대역 소나의
물리 거리 격자를 검사합니다. 특징점 후보에는 측정된 반사 지지가 필요하며,
영상 처리용 값으로 원본 관측을 바꾸지 않습니다.
[입력 계약과 네이티브 연속 처리 대조](docs/diagnostics/sonar-input-contract-20261030/README.ko.md).

`sonar_range_response.PosimRangeResponse`는 소스별 주파수 창 응답과 조건부 산란
파워 모멘트를 계산합니다. 명시적으로 입력한 산란 기하·분산·빔 혼합값으로
거리·빔 픽셀의 의존 관계를 유지합니다.
[가정과 보정 대조](docs/diagnostics/sonar-range-response-20261030/README.ko.md).

`sonar_source_surface.SourceSurfaceObservation`은 소나 좌표계에 주어진 유한한
표면을 계산합니다. 불투명한 첫 교차점의 가림, POSIM의 거리 격자 법선과 픽셀
상관관계를 포함한 전력 모멘트를 유지합니다. 형상과 반사율은 호출자가 제공하는
가설입니다. [소스와 수치 대조](docs/diagnostics/sonar-source-local-power-20261031/README.ko.md).

[소나 관측식의 조건부 결합 진단](docs/diagnostics/sonar-structureless-update-20261030/README.ko.md)은
하나의 추정 분포에 관측을 결합하는 수치 계산, 높이가 불확실한 모드와
같은 시각을 유지한 DVL 생략 대조군을 공개 코드로 재현합니다.

`BeamPhaseBounds.query_image()`는 원본 음향 영상 전체의 반사 기여 진폭 구간을
계산하며, 곱셈 임시 저장공간은 8 MiB 이하입니다. 미지 위상·고도각을 유지하고
반사 지지를 독립된 3차원 점으로 바꾸지 않습니다.
[분리 관측의 기하 검증과 후보 전체 비교](docs/diagnostics/sonar-source-support-20261030/README.ko.md)는
차량 위치의 상관 불확실성, 원래 픽셀의 중복 사용과 실패 사례를 보존합니다.

`retired_pose_archive`는 네이티브 조건부 식에서 과거 자세를 함께 복원하고,
공유 잡음과 관측 불가능한 방향을 보존합니다. 현재 좌표를 알고 있다는 조건의
읽기 전용 진단이며, 기록 기능의 기본값은 꺼짐입니다.
[지연 자세 복원과 공분산의 범위](docs/diagnostics/retired-pose-conditionals-20261029/README.md).

`surface_prior`는 원본 자세를 폐기할 때 자세·미지 평면·압력 기준값의 정보를
함께 보존합니다. 변수 간 상관과 소유자의 고정 참조 좌표를 유지하고, 제한된
원본 거리 기록으로 중복 사용을 막습니다. 네이티브 연결부는 실제 Basalt 좌표를
읽습니다. [지연 갱신 검사와 남은 라이브 통합 조건](docs/diagnostics/persistent-surface-prior-20261029/README.md).

`range_surface_joint`와 네이티브 `makeOwnedRangeSurfaces` 어댑터는 빔별
DVL 원뿔·소나 팬, 현재 자세와 미지 평면을 하나의 상관된 계산 블록에 둡니다.
원본 거리 식별자로 각 제약과 관측 범위의 출처를 추적합니다. 명시적인 평면 대응
가설과 불확실성이 필요하며, 라이브 평면 융합은 아직 활성화하지 않습니다.
[기하·네이티브 최적화기 검사와 상태 보존 한계](docs/diagnostics/joint-surface-ranges-20261029/README.md).

`dvl_surface`는 유한한 빔 원뿔과 국소 평면의 거리 잔차, 자세·평면 Jacobian,
전체 공분산 처리와 국소 관측 범위 검사를 독립적으로 제공합니다.
연결된 평면과 명시적인 불확실성이 필요하며, 앱은 아직 DVL 속도만 융합합니다.
[모델·제어된 측정과 한계](docs/diagnostics/dvl-cone-model-20261029/README.md).

`sonar_plane_intersection`은 측정된 거리·방위각과 주어진 평면이 허용하는
모든 고각 해를 보존합니다. [이동 입력과 관측 중첩 진단](docs/diagnostics/dvl-moving-overlap-20261029/README.md)에
관측 대응과 공간적 지지 범위의 조건을 정리합니다.

`evaluate_dvl_sonar_prediction.py`는 음향 제약을 제외한 자세와 DVL 평면으로
전방 소나의 기하학적 거리를 예측합니다. 관측된 경계 거리를 지지 범위 선택에
사용하지 않습니다. [입력·전체 오차·데이터 위치](docs/diagnostics/sonar-low-altitude-15m-20261029/README.md).

[네이티브 VIO 장시간 운용과 모드 전환](docs/validation/native-vio-lifecycle-20261028/README.md)에 장시간 운용의 전체 지도, 센서 조합 전환과 독립 항법 수신 기록을 보존합니다.

[초기화 계산 대조](docs/validation/seed-scoring-20261028/README.md)에 센서 원본만 사용하는 수치 비교와 소스가 연결된 복구 지도 전체를 보존합니다.

[상태 발행과 VIO 입력 복구](docs/validation/status-publication-vio-20261028/README.md)에 전체 지도 여섯 개, RGB·점군 비교와 실제 GUI 전환 검증을 정리합니다.

[기본 예산의 기준 패치 추적](docs/validation/default-reference-vio-20261028/README.md)에 같은 입력의 추적 방식 대조와 실제 ROS·시뮬레이터 지도를 정리합니다.

[압력 융합·IMU 전송 비교](docs/validation/pressure-event-imu-20261028/README.md)에 전체 지도·기본 예산의 이상점·복구 검증 근거를 보존합니다.

[상태 시각에 맞춘 IMU 전송](docs/diagnostics/event-imu.md)은 카메라·소나 상태의 네이티브 응답을 기다리는 동안 이후 원본 샘플을 제한된 이력에 보존합니다.

[시각 지도의 고정 특징 대응](docs/diagnostics/visual-static-tracks.md)은 시각 트랙과
지도 검사의 물리적 동일성 가정을 설명합니다.

카메라 없는 `SonarSession`은 기본적으로 압력 융합이 명시된 네이티브 보정 설정을 요구합니다. 압력을 끈 명시적 설정은 연구용 대조 실험입니다. 앱의 소나 SLAM은 원본 IMU와 압력 수심을 필수로 사용하고 DVL을 추가할 수 있습니다. 센서 수신과 최근 압력의 실제 융합을 구분하며, 유효한 수심이 도착해야 워커를 시작합니다. 여러 시점의 트랙으로 공유 점 가설을 구속합니다. 압력은 차량 수심을 구속하며 해저까지의 거리를 직접 측정하지 않습니다. 같은 자세의 반복 관측만으로 높이를 구분할 수 없고 물리적 대응·지도 정확도는 미검증입니다.

`SensorEvents.advance`는 검증 후 의도적으로 제외한 관측의 수신 시각을 기록하며, 제약을 생성하거나 이전 측정을 반복하지 않습니다. 입력 정렬과 제약 계산 주기를 분리합니다. 공통 보조 센서 응답·최신성 검사는 측정 수신과 최근 최적화 반영을 구분하고 센서 시계와 실제 경과 시간을 함께 확인합니다.
[카메라·소나·압력 수심 결합과 동일 시점 지도 비교](docs/diagnostics/mixed-sonar-pressure.md).

[카메라 없는 반사 경계 추출과 수직 탐사 비교](docs/diagnostics/sonar-causal-depth.md)에 선택형 원본 소나 추출기와 지도 한계를 정리합니다.

[해저 반사 시작점 지도](docs/diagnostics/sonar-ground-entry.md)는 원본 소나와 선택형 단일 Ping 검사로 조건부 해저 관측을 추출합니다. 고정 추정 자세의 실험에는 실패 사례가 있으며 지형 보조 SLAM 합격을 의미하지 않습니다.
같은 문서에 상관관계를 유지하는 네이티브 거리·평면 제약과 계산 검증을 정리합니다. 실시간 해저 융합은 아직 켜지지 않습니다.

POSIM 애플리케이션에서 사용하는 독립 센서 추정 라이브러리입니다. Python
알고리즘은 센서 측정 배열과 보정된 변환을 받습니다. WWW-POSIM은 세션, 차량
구성, 실행 관리, UI와 지도 다운로드를 담당합니다.

패키지 버전은 **0.1.0**, 음향/DVL 융합 알고리즘 버전은 **0.2.1**입니다.

| 시각 + DVL | 바닥 잠금 속도 적분과 축·회전 레버암 보정; 미터 축척 보정이며 누적 오차의 공동 보정은 아님 |

네이티브 Basalt 카메라 경로는 원본 IMU와 시각 관측을 공동 융합하며, 선택형 단일 Ping 관측도 같은 최적화와 주변화에 참여합니다. Stella 단독 시각 경로와 평면 음향/DVL 경로는 이 VIO 경로와 별개입니다.
시뮬레이터의 정답 위치·자세를 위치 추정 관측으로 사용하지 않습니다.
소나 강도 특징점은 분류된 3D 장애물이 아닙니다.

Ping 축척 관측은 모든 광선 교점이 관측 평면의 볼록 껍질 안에 있고, 각 교점에서 평면 거리의 5% 이내에 특징점이 있어야 합니다. `ping_factor` 모듈은 공동 최적화를 위한 자세·평면 거리 미분과 관측 영역 검사를 제공하며, 네이티브 워커는 대응하는 공동 관측을 `native/basalt/ping_factors.hpp`와 `ping_linearization.hpp`에 구현합니다. `ping_joint`는 거리·표면 잡음을 명시적으로 받아 공동 선형화와 상관관계를 보존하는 평면·특징점 변수 제거의 제한된 참조 구현을 제공합니다.

## 공동 융합 구성 요소

센서 조합별 검증과 문서화에는 [점군/RGB 비교 규약](docs/comparison.md)을
적용합니다.

`sonar_triangulation.point_hypotheses`는 연결된 거리·방위각 트랙과 고정된
추정 자세에서 여러 고도 초기값을 사용해 점 후보를 계산합니다. 대안 해를
유지하고 비용, 국소 랭크와 종료 이유를 보고합니다. 자세 불확실성과 실제
반사점 대응은 해결하지 않으므로 출력은 지도 승인 결과가 아닌 초기값 진단입니다.
기울기, 제안 이동량, 거리·시야 경계 여유와 무효 시도 횟수도 기록합니다.
`no_feasible_trial`은 시도한 이동량이 모두 유효 기하 범위를 벗어났다는 뜻이며,
제약을 만족하는 해가 없거나 트랙이 잘못됐다는 증명은 아닙니다.
점 갱신은 설정된 시야·거리 경계를 선형화한 활성 집합 최소제곱법을 사용하고,
비선형 기하에서 유효성을 다시 검사합니다. 경계 수렴은
`constrained_stationary`로 보고하며 반사점 대응이나 잔차의 적합성을 보장하지
않습니다. 시야를 넓히거나 인위적인 고도 사전정보를 추가하지 않습니다.
`heldout_residuals`는 점 계산에 사용하지 않은 관측을 재최적화 없이 예측합니다.
거리·방위각 잔차를 물리 단위로 보고하고 유효 범위 밖 예측도 셉니다.
계산에 사용한 시각을 검증 집합에 넣을 수 없으며, 이 진단 자체가 보정된
합격 기준을 정의하지는 않습니다.

`native/basalt/sonar_geometry.hpp`는 지도 점의 거리·방위각 잔차를 Basalt의
지도 좌표 이동과 지도 기준 좌측 회전 갱신 규약으로 계산합니다. 자세·점
미분과 설정된 거리·시야 검사를 포함하며 잡음 가중치는 아직 적용하지 않습니다.
네이티브 기하 구성 요소이며, [네이티브 워커](native/basalt/README.md)는
가중 소나 제약·측정 소유권·공동 최적화를 연결합니다. 물리적 반사점 연결과
지형 지도 정확도는 미검증입니다.

`sonar_inertial.optimize_window`는 2–4개 상태 구간의 위치, 속도, 자세,
IMU 바이어스와 공유 소나 반사점을 함께 최적화합니다. 공분산을 포함한 초기
상태 사전정보, 보정된 중력과 센서 장착값, 반사점 초기값, 대응 관계가 있는
거리·방위각 관측과 센서 잡음값이 필요합니다. 비선형 갱신 후 원본 IMU를
다시 사전적분합니다. 한 트랙 안의 시간 상관 잡음을 지원하며, 서로 다른
트랙의 잡음은 독립이라고 가정합니다. 이 NumPy 참조 구현은 국소 랭크를
보고하고 관측 불가능한 방향을 유지합니다. 반사점 고도의 다중 해와 관측
대응 관계는 별도 검증이 필요합니다. 스트리밍 연결과 항법 준비 여부는
아직 검증되지 않았습니다.

선택형 `visual_geometry`와 트랙별 `visual_observations` /
`visual_measurement_covariance`는 왜곡을 보정한 핀홀 영상의 픽셀 잔차를 같은
자세·점 최적화에 추가합니다. 카메라 전용 점과 소나 전용 점은 자세 상태만
공유할 수 있으며, 같은 점 ID는 별도로 확인한 물리적 대응 관계를 뜻합니다.
카메라·소나 잡음 블록은 독립이라고 가정합니다. 카메라 장착, 내부 보정값,
영상 크기와 클립 범위를 명시해야 합니다. 이력 사용 시 시각 관측 중복과
카메라 모델 변경을 거부합니다. 이 참조 경로는 네이티브 VIO 워커를 대체하거나
실시간 센서 간 대응 관계를 제공하지 않습니다.

선택형 `ping_patches`는 같은 최적화에 단일 Ping 관측을 추가합니다. 각
패치는 공유 소나 트랙 ID를 참조하며 면의 법선과 부호 있는 거리를 추정합니다.
평면 제약은 지지점당 한 번, 독립 거리 관측은 해당 상태 시각에 한 번씩
반영합니다. 예측된 빔 교차점은 관측 지지 영역 안에 있어야 합니다. 패치
대응 관계, 국소 평면 가정과 독립적으로 보정된 거리 잡음이 필요합니다.
패치 간 지지점 중복과 거리 관측 시각 중복은 거부합니다.

소나와 Ping 관측은 서로 다른 상태 시점에 속할 수 있습니다. 전방 소나가
앞서 관측한 랜드마크를 나중의 하향 Ping이 제약할 수 있습니다. 각 관측은
정확한 상태 시각을 사용하며 Ping만 있는 상태에는 소나 관측을 요구하지
않습니다. 나중의 Ping 관측 영역도 연결된 랜드마크의 지지 영역 안에 있어야
합니다. 시각 일치만으로 같은 표면임을 인정하지 않습니다. 2–4상태 참조
구간은 인접 상태 사이 최대 3초를 허용합니다. 더 긴 시간차에는 그래프와
패치를 지속적으로 유지하는 처리가 필요하며 이 함수에는 구현되지 않았습니다.

선택형 `retain_state_stamps_ns`는 마지막 공동 선형화에서 나머지 상태를
제거한 `linearized_prior`를 내보냅니다. 직사각형 제곱근 정보 행렬은 남은
상태·랜드마크·평면 사이의 상관관계와 관측되지 않은 방향을 보존합니다.
고정된 선형화 기준값, 평면 접선 기저와 이미 반영한 관측 ID를 함께 담습니다.
`linearized_prior`는 새 초기 상태 사전정보 대신 소나·IMU 이력을 사용합니다.
유지된 랜드마크에는 새 소나 관측이 없어도 되므로 나중의 첫 Ping 제약을
공동 이력에 연결할 수 있습니다. 소나 관측 중복, 겹치는 IMU 구간과 센서·잡음
모델 변경은 거부합니다. 새 관측이 이전 관측과 독립이라는 가정을
`independent_new_measurements=True`로 명시해야 하며, 구간 사이 관측 잡음의
상관관계는 지원하지 않습니다. 사전정보는 저장된 기준값에서 고정됩니다.
Ping 평면은 동일한 순서의 지지점, 센서 기하와 표면 모델을 유지하며 재사용할
수 있습니다. 다음 구간에서는 새 거리 제약만 추가하고 이미 반영한 평면
제약을 반복하지 않습니다. 유지된 패치에는 새 거리값이 없어도 됩니다.
Ping 시각 중복과 패치 모델 변경은 거부합니다. 평면 변화는 저장된 접선 기저를
사용하며 반대 방향 법선은 거부합니다. 실제 표면의 지속적인 대응 관계와
라이브 스트림 연결은 구현되지 않았습니다.

내보낸 사전정보는 QR 압축으로 행 수를 유지 변수 수보다 최대 하나 많게
제한합니다. 야코비안이 0인 한 행에 변수와 직교하는 잔차 비용을 보존하며,
관측되지 않은 방향에 정규화 정보를 추가하지 않습니다. 관측 사용 기록은
이력에 따라 계속 늘어나므로 이 행렬 크기 제한이 전체 스트림 메모리의
상한을 뜻하지는 않습니다.

`inertial_factor.pair_residual`은 측정된 `ImuWindow` 사전적분으로 양 끝 상태의
위치·속도·회전·바이어스를 전체 15상태 공분산과 함께 제약합니다. 중력과 양 끝
상태는 명시적인 최적화 변수입니다. 바이어스 보정은 1차 근사이므로 비선형 갱신
후에는 다시 적분해야 합니다. 실시간 추정기가 아니라 공동 최적화용 잔차입니다.

`sonar_factor.point_return_factor`는 연결된 3D 점 반사에 대한 거리·방위각 잔차와
자세·특징점의 해석적 자코비안을 제공합니다. 보정된 IMU-소나 장착값과 센서의
거리·시야각을 검사하며, 두 관측 차원으로 고도각을 관측했다고 가정하지 않습니다.
NumPy를 사용하는 자체 Apache-2.0 기하 모듈이며 실시간 공동 최적화에는 아직
연결되지 않았습니다. 호출자는 점 반사의 연결 관계와 불확실성을 확인하고 센서 간
상관관계를 유지해야 합니다. 압축된 강도 영상의 한 픽셀을 알려진 해저점으로
간주할 수 없습니다.

`acoustic_flow.correspondences`는 최대 300개의 두 프레임 강도 추적 후보를
나노초 정수 시각, 대응 픽셀, 보정된 거리·방위각, 전후방 픽셀 오차와 함께
제공합니다. 평면 추정 전에 실행하므로 평면 추정에 실패해도 후보를 보존할 수
있습니다. 쌍 내부의 인덱스는 전역 특징점 ID가 아니며 픽셀 일관성이 영구적인
점 반사나 보정된 공분산을 보장하지 않습니다.
`estimate(..., include_correspondences=True)`로 후보 출력을 명시적으로 선택하며
기본 스트리밍 상태에는 큰 후보 목록을 추가하지 않습니다.

`acoustic_tracks.AcousticTracks`는 최대 300개의 강도 추적 연결을 프레임 간에
유지합니다. 살아남은 픽셀을 다음 추적의 시작점으로 사용하며 새 특징에는 구간
내에서 새 ID를 부여합니다. 시간 공백, 잘못된 보정값과 전체 추적 손실은 구간을
나눕니다. 한 픽셀 영역에서 충돌하는 연결은 제외합니다. 고도각은 미관측 상태로
남기며 실제 반사 물체의 동일성을 보장하지 않습니다. 실시간 공동 최적화에는
아직 연결되지 않았습니다.

`sonar_joint.linearize_track`는 동일한 반사점에 연결된 최대 16개 관측의
자세·특징점 선형식을 구성합니다. 정확히 일치하는 상태 시각과 시간 간 상관관계를
포함한 거리·방위각 공분산을 명시적으로 입력해야 합니다. 같은 특징점을 사용하는
시각·Ping 관측을 먼저 합친 뒤 기존 `ping_joint.eliminate_patch`로 특징점 변수를
제거해야 합니다. 임의의 고도각이나 자세 사전 제약을 추가하지 않습니다.
실시간 융합 SLAM이 아니라 최적화 구현을 위한 구성 요소입니다.

## 설치와 사용

Python 3.10 이상과 NumPy가 필요합니다. 순수 기하 알고리즘에는 ROS·Gazebo·
WWW-POSIM이 필요하지 않습니다.

```sh
git clone https://github.com/IOES-Lab/POSIM-SLAM.git
cd POSIM-SLAM
python -m venv .venv
. .venv/bin/activate
python -m pip install -e .
```

Windows에서는 `.venv\Scripts\activate`로 활성화합니다.

```python
from posim_slam.inertial import ImuWindow

imu = ImuWindow()
for i in range(201):
    imu.add(i / 200., [0., 0., 0.], [0., 0., 9.80665])
delta = imu.preintegrate(0., 1., gyro_bias=[0., 0., 0.],
                        accel_bias=[0., 0., 0.],
                        noise_density=[.002, .02, .0001, .001])
```

잡음 수치는 사용 예시이며 하드웨어 보정값이 아닙니다. 전적분 결과는 중력과 초기
속도를 포함하지 않습니다. 후속 추정기가 독립 관측으로 위치·속도·바이어스를 함께
갱신해야 합니다.

음향 영상 추적에는 검증된 OpenCV 4.13.0 네이티브 공급자 또는 연구용 추가 패키지
(`python -m pip install -e '.[research]'`)가 필요합니다. 네이티브 공급자는
`POSIM_SLAM_ACOUSTIC_LIBRARY`를 사용하며 기존 `WWOS_ACOUSTIC_NATIVE_LIBRARY`도
지원합니다. SDK, 소스·라이브러리 해시와 ABI를 검사합니다. 연구용 cv2 설치는 실제
네이티브 실행 검증을 대신하지 않습니다.

## 실험적인 시각·관성 연구

[Headless Basalt 대상](native/basalt/README.md#한국어)은 버전을 고정한 square-root
VIO 코어를 빌드하고 잡음이 있는 6자유도 특징·영상과 원본 IMU 회귀를 실행합니다.
이 독립 실행 파일에서는 위치·속도·자세와 바이어스를 함께 갱신합니다. Python
패키지는 실행 파일을 포함하지 않습니다. 호스트 앱이 워커 등록·실행 관리와 기본
모드 선택을 담당합니다. 실제
월드의 시각·보정·복구와 배포 패키지는 별도로 검증해야 합니다.

네이티브 카메라 인터페이스는 `optical_flow_type`으로 이전 프레임 참조
추적(기본값)과 최초 프레임 참조 추적을 제공합니다. 최초 프레임 참조는
모든 카메라에서 마지막 관측이 사라지면 해제합니다.
[참조 패치 협약](native/basalt/README.md#visual-reference-patches--시각-참조-패치)을 확인하세요.

## 실험적 관성 관측 필터

`posim_slam.inertial_filter.InertialFilter`는 위치·속도·IMU 자세·gyro/accel
바이어스로 한 로컬 구간을 추정합니다. 연속 잡음 밀도 순서는 gyro, accel,
gyro 바이어스 random walk, accel 바이어스 random walk입니다. 보정값·초기 상태·
양의 정부호 공분산을 명시해야 합니다. 관측은 예측 상태의 시각과 일치해야 하며,
지연 관측은 호출자가 재생해야 합니다. 같은 시각의 관측을 중복 소비하지 않습니다.
DVL은 물리 장착 축과 회전 레버암을 보정합니다. 수압 입력은 보정한 ENU 센서
높이이며 Ping 거리가 아닙니다. 복제 자세는 평면 음향 상대 이동·yaw 관측의
교차 공분산을 유지합니다. 평면 밖 이동과 기울기가 설정 한도를 넘으면 거부하며,
소나 에코의 높이나 전역 루프 폐쇄를 해결하지 않습니다.

Innovation gate, Joseph 공분산 갱신, 우측 자세 오차 재설정을 사용합니다.
동일 관측 종류의 innovation을 연속 세 번 거부하거나 IMU 구간이 누락되면 구간이
무효화됩니다. 호출자는 연결된 지도를 비우고 다시 초기화하며, 필수 센서의 신선도와
예측 시간 상한도 검사해야 합니다. 통계적 gate는 초기화 관측 가능성을 보장하지
않습니다. [오차 상태 수식](https://arxiv.org/abs/1711.02508)을 따르는 자체 Apache-2.0
코드이며 추가 의존성은 NumPy뿐입니다.

```sh
PYTHONPATH=src python tools/evaluate_inertial_filter.py --output /tmp/inertial.json
```

6개 시드의 합성 6DoF 실험은 알려진 로컬 좌표계의 초기 자세 prior와 2초 정지
raw gyro 보정을 사용합니다. 정답 관측 갱신이나 축척 정렬 없이 IMU 예측과
DVL·수압 갱신을 비교합니다. 네이티브 초기화·현장 정확도·음향 지도 연결·앱 기본값의
승인 시험은 아닙니다.

## 움직이는 상태의 카메라/IMU 초기값

`visual_inertial_seed.tracked_imu_seed`는 보정된 다중 시점 영상 특징점과
원시 IMU로 미터 단위 속도·중력의 임시 초기값을 구합니다. 중력 크기와 픽셀
잡음을 명시하면 제한된 RANSAC 특징점 일치 검사와 중력 접평면 보정을
사용합니다. 바이어스는 주어진 입력값으로 취급하며 초기화 불확실성 검증이
필요합니다. [입력과 방법](docs/diagnostics/visual-inertial-seed.md).

## 움직이는 상태의 IMU/DVL 초기화

`posim_slam.inertial_alignment.moving_initialize` 알고리즘 **0.1.0**은 7–30초
raw IMU와 바닥 잠금 DVL 끝점 8–24개에 유한 구간 팩터 그래프를 적용합니다.
인접 끝점 간격은 최대 1.5초입니다. 명시한 보정 prior를 사용해 중력, 끝점별
자세·속도, 구간 내 일정한 gyro/accel 바이어스를 추정합니다. DVL 장착 회전과
회전에 따른 레버암 속도를 반영하고 마지막 끝점을 로컬 원점으로 정합니다.
초기 yaw는 로컬 좌표계의 기준입니다.

파도·조류에 의한 움직임에 정지 RMS 임계값을 요구하지 않습니다. IMU 누락,
바닥 잠금 상실, 불명확한 공분산, 시간 간격 초과, 관측 불일치, 수렴 실패는
구간 거부 사유입니다. 추정 결과에는 자세·속도의 3시그마 불확실성 한계와 상태
교차 공분산이 포함됩니다. 작은 잔차나 수치적 rank만으로 바이어스 관측 가능성이나
항법 준비를 보장하지 않습니다. 운동 변화가 작은 경우 바이어스 보정에 의존하며,
전송 계층에서 출처 검증과 수명 주기를 관리해야 합니다. 수압도 같은 로컬 수직 원점을 사용해야 합니다.

합성 이동 시험은 독립적인 잡음 포함 gyro 보정 측정값을 사용한 뒤 12초 동적
초기화와 8초 추적을 수행합니다. 자세·위치 관측은 입력하지 않습니다.
`--weak-prior`는 보정하지 않은 평균 0 gyro 바이어스에 같은 정확도 기준을
적용하며, 잔차가 통과해도 정확도 시험은 실패할 수 있습니다. 이 프로필로
설치된 센서를 검증한 것으로 판단하지 않습니다.

```bash
PYTHONPATH=src python tools/evaluate_moving_initialization.py --output /tmp/moving.json
```

아래 정지 초기화는 잔잔한 조건에서 선택하는 방법입니다. 안내 시간 30초가
지났다고 수렴이나 준비 완료를 보장하지 않습니다.


양의 준정부호 바이어스 prior는 정확히 보정된 방향을 표현할 수 있습니다.
해당 방향은 작은 분산으로 근사하지 않고 최적화 변수에서 제거합니다. 알 수 없는
공분산을 0으로 표시하면 안 됩니다. 호출자가 보정 출처를 확인해야 하며 잡음이
있는 실제 센서는 측정한 prior가 필요합니다. 위치·속도·자세의 상태 공분산은
양의 정부호를 유지합니다.

## 스트리밍 관성 추정 수명 주기

`InertialDvlSession`은 동적 초기화와 이후 IMU/DVL 갱신을 관리합니다. 실제
바닥 잠금 DVL과 raw IMU가 최소 12초를 덮을 때 초기화하고 사후 3시그마의
최댓값을 검사합니다. 기준은 자세 3도, 속도 0.1 m/s입니다. IMU 32,768개와
DVL 2,048개를 보존하며 초기화 그래프는 DVL 끝점 24개로 제한합니다.
`ImuWindow`의 기본 보존 수는 8,192개이며 고주파 처리에는 32–65,536개
범위에서 용량을 명시할 수 있습니다.

DVL이 IMU보다 먼저 도착하면 실제 끝점 측정이 들어올 때까지 기다립니다.
잘못된 시각, IMU 누락, 바닥 잠금 상실, 반복 관측 거부 또는 오래된 센서 입력은
구간을 무효화하고 자세 출력을 지웁니다. 복구에는 새 동적 구간을 수집합니다.
출력 시각은 DVL 획득 시각이며 발행 시각으로 바꾸지 않습니다. 전송 계층은
출처·세션을 검증하고 입력 큐 크기를 제한해야 합니다. 출력은 로컬 관성
오도메트리이며 지도나 항법 준비 판정을 제공하지 않습니다.

## 측정값으로 정지 초기화

`posim_slam.inertial_initialization.stationary_initialize` 알고리즘 **0.1.0**은
2–3초 raw IMU와 구간 전체를 덮는 바닥 잠금 DVL 표본 3개 이상으로 독립 필터를
시작합니다. DVL 간격 상한은 1.5초입니다. 물리 장착, 잡음 밀도, accel 바이어스
보정·공분산과 잔여 운동 불확실성을 명시해야 합니다. DVL 공분산이 0이거나
불명확하면 거부합니다. 실험적 저잡음 정지 프로필의 조건은 평균 gyro 크기
≤0.03 rad/s, gyro RMS ≤0.02 rad/s, accel RMS ≤0.12 m/s², 중력 크기 차이
≤0.25 m/s², 각 DVL 속도와 3σ의 합 ≤0.06 m/s입니다. 모든 센서에 보정된 기본
한도라는 뜻은 아닙니다.

평균 specific force로 roll/pitch를 구하며 뒤집힌 IMU 장착도 처리합니다.
초기 위치·yaw는 중력에 맞춘 로컬 좌표계의 기준이며 지리 방위가 아닙니다.
정지 gyro 평균으로 gyro 바이어스를 구합니다. accel 바이어스는 초기 기울기와의
교차 공분산을 유지하는 보정 prior이며, 정지만으로 중력과 모든 바이어스 성분을
분리하지 않습니다. DVL은 선형 정지를, IMU 변화량은 각운동의 정지를 뒷받침합니다.
일부 일정한 운동은 모호하게 남으므로 gate 통과가 전체 관측 가능성·항법 준비를
보장하지 않습니다. 정답 자세·위치를 입력받지 않으며 앱 어댑터는 아직 없습니다.

```sh
PYTHONPATH=src python tools/evaluate_stationary_initialization.py --output /tmp/initialization.json
```

합성 장면은 정지 측정값으로 시작한 뒤 20초의 부드러운 6DoF 운동을 수행합니다.
정답은 측정 생성과 평가에만 사용하며, 초기 로컬 위치·yaw 좌표계를 기준으로
궤적·축척 피팅 없이 평가합니다.

수압 관측은 초기화한 로컬 수직 기준으로 변환해야 합니다. 절대 해수면 기준 높이와
0으로 정한 로컬 원점을 그대로 혼용할 수 없습니다.

## 다중 표본 중력 초기값

`posim_slam.gravity_seed.gravity_seed`는 데이터가 완전히 덮인 0.2–3초의
`ImuWindow`에서 보정된 비력을 평균합니다. 중점 자이로 적분으로 각 표본을
마지막 IMU 좌표계로 옮긴 뒤 사다리꼴 적분을 적용합니다. 자이로와 가속도계의
바이어스 추정값을 명시해야 합니다. 반환 방향은 수치적인 초기값이며 속도·바이어스·
관측 가능성 추정이 아닙니다. 잡음이 없어도 일정한 병진 가속도에 의해 편향될 수
있습니다. 네이티브 Basalt 작업자는 보정 설정의 `require_gravity_seed`가 켜져 있으면
첫 영상의 타임스탬프와 결합된 초기값 패킷으로 이 방향을 받습니다. 원본 IMU 패킷은
그대로 유지하며 속도와 바이어스 초기값에는 별도의 가정이 필요합니다.

`sonar_input.projected_frame`은 크기를 제한한 float32 멀티빔 메시지를 두 바이트 순서로 읽습니다. 시각·거리 구간·단위 빔 방향을 검증하며 음의 무한대는 반사 없음으로 보존합니다. 디코더는 ROS에 의존하지 않습니다.

음향/DVL 구간은 소나 평면에 수직인 속도를 보존하며, 평면 밖 이동이 5 cm를 넘으면 거부합니다. 최종 변위가 0인 왕복 운동도 검사합니다. 이는 실험적인 모델 유효성 검사이며 높이 복원이나 확률적 신뢰도를 뜻하지 않습니다.

## 기록된 입력의 라이브 작업자 비교

`tools/stream_recording.py --gravity-seed`는 측정된 IMU 기록이 1초 이상 있는 첫 영상을 선택하고, 회전을 보정한 중력 초기값과 200 ms IMU 시작 버퍼를 전달합니다. 이후 영상은 모두 평가 순서에 유지합니다. 결과 기록에는 초기화에 사용해 제외한 영상 수와 정확한 초기값이 남습니다. 초기 속도와 바이어스는 여전히 0으로 가정합니다.

`--joint-ping`을 추가하면 영상과 타임스탬프가 정확히 일치하는 기록된 거리를 융합합니다. 두 Ping 파일 모두 검증된 기록 해시 목록에 있어야 합니다. 유효하지 않은 반환값은 제외하며 가까운 시각의 값으로 대신하지 않습니다. 같은 기록에서 이 옵션을 빼고 반복하면 카메라/IMU와 카메라/IMU/Ping을 비교할 수 있습니다. `states.json`에는 자세 CSV와 함께 네이티브 진단값을 보존합니다. 이 도구는 센서 시각의 입력과 수치 초기화를 재현하며 ROS 콜백 시각이나 정확도 합격을 보증하지 않습니다.

네이티브 스트림 상태의 `initialization_window`는 최적화 후, 주변화 전에 남아 있는 가장 오래된 상태를 담습니다. 시각·자세·위치·속도·바이어스를 통해 처음 발행된 예측과 이후 최적화 창의 보정을 구분할 수 있습니다. 이 필드는 초기화 합격을 보증하거나 추정기 입력을 변경하지 않습니다.

선택형 네이티브 입력 `record_visual_tracks: true`는 같은 폴더의
`*.visual-tracks.jsonl`에 최대 1,800개 지도 프레임을 기록하고, 초과하면
명시적인 잘림 표시를 남깁니다. 실제 추적 ID·픽셀, 사용 가능한 최적화된
3차원 좌표, 재투영 오차, 전체 가중치 여부와 현재 성숙 점군의 보존 여부를
함께 기록합니다. 픽셀 좌표는 기록된 처리 영상의 너비·높이를 기준으로
합니다. 기본값은 꺼짐입니다. 이 기록은 형상이 사라지는 단계를 진단하며
특징점 선택·삼각측량·점군 채택을 바꾸지 않습니다. 네이티브
`basalt_visual_trace_probe`는 ID와 처리 단계의 구분을 검사합니다.

네이티브 작업자는 시각 랜드마크가 생길 때까지 초기 속도·바이어스 상태를 보존합니다. 스트림은 보존 상태 창이 128개 상태 또는 센서 시각 30초를 넘으면 거부합니다. 이후 시각 제약으로 보정할 변수를 유지하는 처리이며, IMU만으로 초기 속도를 추정하거나 초기화 합격을 뜻하지 않습니다.

`--gravity-seed`와 함께 `--first-image-stamp-ns`를 지정하면 기록된 라이브 시작 시각을 재현합니다. 요청한 시각의 영상이 정확히 존재하고 IMU 이력이 해당 구간을 덮어야 합니다. 지연된 주변화에서는 사전 제약을 구성하기 전에 새로 보존하는 각 자세의 선형화 기준점을 설정하며, 기존 기준점은 유지합니다.
