# POSIM-SLAM

[English](README.md) · [제3자 고지](THIRD_PARTY.md)

POSIM 애플리케이션에서 사용하는 독립 센서 추정 라이브러리입니다. Python
알고리즘은 센서 측정 배열과 보정된 변환을 받습니다. WWW-POSIM은 세션, 차량
구성, 실행 관리, UI와 지도 다운로드를 담당합니다.

패키지 버전은 **0.1.0**, 음향/DVL 융합 알고리즘 버전은 **0.2.0**입니다.

| 구성 | 방법과 현재 범위 |
|---|---|
| 시각 공급자 | Stella VSLAM 0.7.0 단안 ORB 특징과 g2o/Eigen 최적화; ROS 2 어댑터와 정확한 의존성 버전 포함; 임의 축척; 빈 사전 구성의 루프 폐쇄·재위치 추정은 미검증 |
| 시각 + 단일 Ping | 강건한 국소 평면 적합, 동기화 거리와 장착 위치·바이어스 보정, 안정된 중앙값으로 미터 축척 추정; 적합한 하향 시야와 국소 평면 해저 필요 |
| 시각 + DVL | 바닥 잠금 속도 적분과 축·회전 레버암 보정; 미터 축척 보정이며 누적 오차의 공동 보정은 아님 |
| 음향 전처리 | OpenCV Shi–Tomasi 코너, 양방향 피라미드 Lucas–Kanade 광류, 소나 팬 평면의 SVD/RANSAC 강건 2D 정합 |
| 음향 + DVL | 구간을 덮는 속도 적분으로 이동량 추정; 음향 회전·특징과 이동량 일관성 검사; 실험적인 평면 오도메트리이며 높이 미확정 |
| 수면 필터 | 수압·자세로 평균 수면을 보정하고 미터 지도를 자름; 개별 수면 에코 분류는 지원하지 않음 |
| 관성 코어 | 원본 각속도·가속도의 중점 SO(3) 전적분, 바이어스 Jacobian, 15상태 오차 공분산; 완전한 융합 추정기가 아닌 준비 코드 |
| 실험적 관성 필터 | 알고리즘 0.1.0: 15상태 우측 오차 EKF, raw IMU 예측, 장착 보정 DVL 속도, 보정된 수압 높이, 상관 공분산을 유지하는 복제 자세의 평면 상대 관측 갱신; 초기 상태·보정 명시 필요; 스트리밍 IMU/DVL 구간 관리 |

실행되는 시각·음향 모드는 아직 관성 전적분 코어를 사용하지 않습니다.
시뮬레이터의 정답 위치·자세를 위치 추정 관측으로 사용하지 않습니다.
소나 강도 특징점은 분류된 3D 장애물이 아닙니다.

Ping 축척 관측은 모든 광선 교점이 관측 평면의 볼록 껍질 안에 있고, 각 교점에서 평면 거리의 5% 이내에 특징점이 있어야 합니다. `ping_factor` 모듈은 공동 최적화를 위한 자세·평면 거리 미분과 관측 영역 검사를 제공하며, 아직 네이티브 VIO 워커에 연결되지는 않았습니다.

## 설치와 사용

Python 3.10 이상과 NumPy가 필요합니다. 순수 기하 알고리즘에는 ROS·Gazebo·
WWW-POSIM이 필요하지 않습니다.

```sh
git clone https://github.com/IOES-Lab/POSIM-SLAM.git
cd POSIM-SLAM
python -m venv .venv
. .venv/bin/activate
python -m pip install -e .
```

Windows에서는 `.venv\Scripts\activate`로 활성화합니다.

```python
from posim_slam.inertial import ImuWindow

imu = ImuWindow()
for i in range(201):
    imu.add(i / 200., [0., 0., 0.], [0., 0., 9.80665])
delta = imu.preintegrate(0., 1., gyro_bias=[0., 0., 0.],
                        accel_bias=[0., 0., 0.],
                        noise_density=[.002, .02, .0001, .001])
```

잡음 수치는 사용 예시이며 하드웨어 보정값이 아닙니다. 전적분 결과는 중력과 초기
속도를 포함하지 않습니다. 후속 추정기가 독립 관측으로 위치·속도·바이어스를 함께
갱신해야 합니다.

음향 영상 추적에는 검증된 OpenCV 4.13.0 네이티브 공급자 또는 연구용 추가 패키지
(`python -m pip install -e '.[research]'`)가 필요합니다. 네이티브 공급자는
`POSIM_SLAM_ACOUSTIC_LIBRARY`를 사용하며 기존 `WWOS_ACOUSTIC_NATIVE_LIBRARY`도
지원합니다. SDK, 소스·라이브러리 해시와 ABI를 검사합니다. 연구용 cv2 설치는 실제
네이티브 실행 검증을 대신하지 않습니다.

## 네이티브 빌드

일치하는 OpenCV 4.13.0 개발 환경에서 실행합니다.

```sh
cmake -S native -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
cmake --install build --prefix install
```

시각 ROS 2 어댑터에는 고정된 Stella 의존성 빌드도 필요합니다. 해당 환경에서
`POSIM_SLAM_BUILD_VISUAL=ON`을 설정합니다. 공급자 실행·경로 이동 검증은 CMake
빌드 성공과 별개입니다. 현재 음향 공급자 기록은 macOS `.dylib` 레이아웃을
사용하며 Windows 네이티브 공급자 실행은 미검증입니다.

## 무결성과 시험

```sh
python -m pip install -e '.[research]'
python -m unittest discover -s tests
```

시험은 해석 가능한 축척·회전·가속, 구간 데이터, 시각·세션 초기화, 비정상 측정,
수면 자르기, 바이어스 미분과 공분산을 확인합니다. `test_integrity.py`는 소스 버전,
원본 고지 해시와 WWW-POSIM 애플리케이션 import 부재를 확인합니다. 장시간 SLAM
정확도는 별도 센서 실행과 독립 정답 비교로 검증해야 합니다.

소스 버전과 패치는 `src/posim_slam/data/visual`, 네이티브 어댑터는
`src/posim_slam/data/native`에 있습니다. 이 자료와 제3자 고지는 Python 패키지에도
포함되어 체크아웃·wheel·복원 환경에서 같은 소스를 사용합니다.

자체 코드는 [Apache-2.0](LICENSE)입니다. [NOTICE.md](NOTICE.md)와 제3자 라이선스를
확인하세요. ORB-SLAM3 코드·특징 사전·학습 가중치는 포함하지 않습니다.
Basalt와 Kimera는 이 패키지에서 실행되는 백엔드가 아닙니다.

## 실험적인 시각·관성 연구

[Headless Basalt 대상](native/basalt/README.md#한국어)은 버전을 고정한 square-root
VIO 코어를 빌드하고 잡음이 있는 6자유도 특징·영상과 원본 IMU 회귀를 실행합니다.
이 독립 실행 파일에서는 위치·속도·자세와 바이어스를 함께 갱신합니다. WWW-POSIM이
선택하는 백엔드나 기본 Python·네이티브 공급자 빌드에는 포함하지 않습니다. 실제
월드의 시각·보정·복구와 배포 패키지는 별도로 검증해야 합니다.

## 실험적 관성 관측 필터

`posim_slam.inertial_filter.InertialFilter`는 위치·속도·IMU 자세·gyro/accel
바이어스로 한 로컬 구간을 추정합니다. 연속 잡음 밀도 순서는 gyro, accel,
gyro 바이어스 random walk, accel 바이어스 random walk입니다. 보정값·초기 상태·
양의 정부호 공분산을 명시해야 합니다. 관측은 예측 상태의 시각과 일치해야 하며,
지연 관측은 호출자가 재생해야 합니다. 같은 시각의 관측을 중복 소비하지 않습니다.
DVL은 물리 장착 축과 회전 레버암을 보정합니다. 수압 입력은 보정한 ENU 센서
높이이며 Ping 거리가 아닙니다. 복제 자세는 평면 음향 상대 이동·yaw 관측의
교차 공분산을 유지합니다. 평면 밖 이동과 기울기가 설정 한도를 넘으면 거부하며,
소나 에코의 높이나 전역 루프 폐쇄를 해결하지 않습니다.

Innovation gate, Joseph 공분산 갱신, 우측 자세 오차 재설정을 사용합니다.
동일 관측 종류의 innovation을 연속 세 번 거부하거나 IMU 구간이 누락되면 구간이
무효화됩니다. 호출자는 연결된 지도를 비우고 다시 초기화하며, 필수 센서의 신선도와
예측 시간 상한도 검사해야 합니다. 통계적 gate는 초기화 관측 가능성을 보장하지
않습니다. [오차 상태 수식](https://arxiv.org/abs/1711.02508)을 따르는 자체 Apache-2.0
코드이며 추가 의존성은 NumPy뿐입니다.

```sh
PYTHONPATH=src python tools/evaluate_inertial_filter.py --output /tmp/inertial.json
```

6개 시드의 합성 6DoF 실험은 알려진 로컬 좌표계의 초기 자세 prior와 2초 정지
raw gyro 보정을 사용합니다. 정답 관측 갱신이나 축척 정렬 없이 IMU 예측과
DVL·수압 갱신을 비교합니다. 네이티브 초기화·현장 정확도·음향 지도 연결·앱 기본값의
승인 시험은 아닙니다.

## 움직이는 상태의 IMU/DVL 초기화

`posim_slam.inertial_alignment.moving_initialize` 알고리즘 **0.1.0**은 7–30초
raw IMU와 바닥 잠금 DVL 끝점 8–24개에 유한 구간 팩터 그래프를 적용합니다.
인접 끝점 간격은 최대 1.5초입니다. 명시한 보정 prior를 사용해 중력, 끝점별
자세·속도, 구간 내 일정한 gyro/accel 바이어스를 추정합니다. DVL 장착 회전과
회전에 따른 레버암 속도를 반영하고 마지막 끝점을 로컬 원점으로 정합니다.
초기 yaw는 로컬 좌표계의 기준입니다.

파도·조류에 의한 움직임에 정지 RMS 임계값을 요구하지 않습니다. IMU 누락,
바닥 잠금 상실, 불명확한 공분산, 시간 간격 초과, 관측 불일치, 수렴 실패는
구간 거부 사유입니다. 추정 결과에는 자세·속도의 3시그마 불확실성 한계와 상태
교차 공분산이 포함됩니다. 작은 잔차나 수치적 rank만으로 바이어스 관측 가능성이나
항법 준비를 보장하지 않습니다. 운동 변화가 작은 경우 바이어스 보정에 의존하며,
전송 계층에서 출처 검증과 수명 주기를 관리해야 합니다. 수압도 같은 로컬 수직 원점을 사용해야 합니다.

합성 이동 시험은 독립적인 잡음 포함 gyro 보정 측정값을 사용한 뒤 12초 동적
초기화와 8초 추적을 수행합니다. 자세·위치 관측은 입력하지 않습니다.
`--weak-prior`는 보정하지 않은 평균 0 gyro 바이어스에 같은 정확도 기준을
적용하며, 잔차가 통과해도 정확도 시험은 실패할 수 있습니다. 이 프로필로
설치된 센서를 검증한 것으로 판단하지 않습니다.

```bash
PYTHONPATH=src python tools/evaluate_moving_initialization.py --output /tmp/moving.json
```

아래 정지 초기화는 잔잔한 조건에서 선택하는 방법입니다. 안내 시간 30초가
지났다고 수렴이나 준비 완료를 보장하지 않습니다.


양의 준정부호 바이어스 prior는 정확히 보정된 방향을 표현할 수 있습니다.
해당 방향은 작은 분산으로 근사하지 않고 최적화 변수에서 제거합니다. 알 수 없는
공분산을 0으로 표시하면 안 됩니다. 호출자가 보정 출처를 확인해야 하며 잡음이
있는 실제 센서는 측정한 prior가 필요합니다. 위치·속도·자세의 상태 공분산은
양의 정부호를 유지합니다.

## 스트리밍 관성 추정 수명 주기

`InertialDvlSession`은 동적 초기화와 이후 IMU/DVL 갱신을 관리합니다. 실제
바닥 잠금 DVL과 raw IMU가 최소 12초를 덮을 때 초기화하고 사후 3시그마의
최댓값을 검사합니다. 기준은 자세 3도, 속도 0.1 m/s입니다. IMU 32,768개와
DVL 2,048개를 보존하며 초기화 그래프는 DVL 끝점 24개로 제한합니다.
`ImuWindow`의 기본 보존 수는 8,192개이며 고주파 처리에는 32–65,536개
범위에서 용량을 명시할 수 있습니다.

DVL이 IMU보다 먼저 도착하면 실제 끝점 측정이 들어올 때까지 기다립니다.
잘못된 시각, IMU 누락, 바닥 잠금 상실, 반복 관측 거부 또는 오래된 센서 입력은
구간을 무효화하고 자세 출력을 지웁니다. 복구에는 새 동적 구간을 수집합니다.
출력 시각은 DVL 획득 시각이며 발행 시각으로 바꾸지 않습니다. 전송 계층은
출처·세션을 검증하고 입력 큐 크기를 제한해야 합니다. 출력은 로컬 관성
오도메트리이며 지도나 항법 준비 판정을 제공하지 않습니다.

## 측정값으로 정지 초기화

`posim_slam.inertial_initialization.stationary_initialize` 알고리즘 **0.1.0**은
2–3초 raw IMU와 구간 전체를 덮는 바닥 잠금 DVL 표본 3개 이상으로 독립 필터를
시작합니다. DVL 간격 상한은 1.5초입니다. 물리 장착, 잡음 밀도, accel 바이어스
보정·공분산과 잔여 운동 불확실성을 명시해야 합니다. DVL 공분산이 0이거나
불명확하면 거부합니다. 실험적 저잡음 정지 프로필의 조건은 평균 gyro 크기
≤0.03 rad/s, gyro RMS ≤0.02 rad/s, accel RMS ≤0.12 m/s², 중력 크기 차이
≤0.25 m/s², 각 DVL 속도와 3σ의 합 ≤0.06 m/s입니다. 모든 센서에 보정된 기본
한도라는 뜻은 아닙니다.

평균 specific force로 roll/pitch를 구하며 뒤집힌 IMU 장착도 처리합니다.
초기 위치·yaw는 중력에 맞춘 로컬 좌표계의 기준이며 지리 방위가 아닙니다.
정지 gyro 평균으로 gyro 바이어스를 구합니다. accel 바이어스는 초기 기울기와의
교차 공분산을 유지하는 보정 prior이며, 정지만으로 중력과 모든 바이어스 성분을
분리하지 않습니다. DVL은 선형 정지를, IMU 변화량은 각운동의 정지를 뒷받침합니다.
일부 일정한 운동은 모호하게 남으므로 gate 통과가 전체 관측 가능성·항법 준비를
보장하지 않습니다. 정답 자세·위치를 입력받지 않으며 앱 어댑터는 아직 없습니다.

```sh
PYTHONPATH=src python tools/evaluate_stationary_initialization.py --output /tmp/initialization.json
```

정답은 측정 생성과 평가에만 사용하며, 초기 로컬 위치·yaw 좌표계를 기준으로
