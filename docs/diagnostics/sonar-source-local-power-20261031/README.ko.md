# 소나 좌표계 음향 관측 모델 대조

[English](README.md)

공개 NumPy `SourceSurfaceObservation`은 소나 좌표계에 주어진 유한한 불투명
표면을 계산합니다. 첫 교차점의 가림, float32 거리 격자, POSIM의 거리 격자
법선, 정확한 이산 Hamming 응답과 조건부 픽셀 상관관계를 유지합니다. 반사율은
기하학적 가림과 별도로 산란원 전력을 정합니다. 표면 추정이나 네이티브 팩터
추가는 수행하지 않습니다.

## 소스와 범위

기준 소스는 POSIM `ffecee9be9976f68c9e883d6cf3bbd6d40eb7729`입니다.
현재 main에 #6과 #31–36을 포함한 별도 통합 브랜치이며, 원본 PR은 미병합
상태입니다. `RaySurfaceNormals.hh`의 세 번째 성분에는 이미 광선 입사각이
들어갑니다. 음향 셰이더의 `normal.z` 사용은 이 규약과 일치합니다. 이번
대조는 음향 셰이더·설치 SDK·ABI·잡음·센서 기본값·지도 수용 규칙을 변경하지
않습니다. [Apache-2.0 고지](https://github.com/IOES-Lab/POSIM-SLAM/blob/codex/reference-patch-tracking/THIRD_PARTY.md#posim-acoustic-model-adaptation--posim-음향-모델-이식)에
이식한 원본 소스를 명시합니다.

1.5° 이웃 범위, 최대 25개 거리 표본, 불연속점에서 가까운 쪽의 접선과 원본의
조건부 국소 평면 적합을 유지합니다. 원본은 float32 삼각함수 값을 double
형상 계산으로 올립니다. 초기 double 삼각함수 이식은 원래 동등성 기준을
통과하지 못했고 전체 결과를 `normal-reference-first-comparison.json`에
보존합니다. 원본의 계산 정밀도를 유지해 차이를 해결했으며 허용 오차는
그대로입니다.

전체 거리 격자 대조 10개에는 256×256 유한 가림 물체, 평면, 일정 구면 거리,
누락·고립 반사, 비균일 각도와 작은 팬이 포함됩니다. 기존 OpenCV 4.13.0으로
변경하지 않은 C++ 함수를 실행합니다. 모든 법선의 0/비0 마스크가 일치하고,
수정 후 최대 성분 차이는 **3.13×10⁻⁶**입니다. 사전 지정한 소스 동등성
허용 오차 **2×10⁻⁵** 이내입니다. `native-normals.npz`는 모든 입력과
네이티브 출력을 보존합니다. 주어진 배열로 실제 네이티브 법선 함수를 실행한
결과이며 Gazebo 센서 취득이나 실물 장치 보정 결과는 아닙니다.

## 조건부 전력 모멘트

`SourceSurfaceObservation`은 주어진 소나 좌표계 삼각형의 첫 교차점을 구하고
거리 격자 법선을 계산한 뒤 기존 `sonar_speckle`의 Fourier 진폭과 모멘트를
재사용합니다. 이상적 법선의 형상 미분은 제공하지 않습니다. 근거리 클리핑을
가로지르는 교차점은 지원하지 않습니다. 가우시안 산란원의 조건부 모멘트는
`K = H diag(q) H*`, 평균 `diag(K)`, 전력 공분산 `abs(K)²`입니다. 픽셀을
평균할 때도 상관관계를 유지하며 픽셀 독립성을 가정하지 않습니다.

주어진 유한 해저·상자 대조는 15 m 개발 프로필인 256빔·수직 광선 256개·
599빈·29,900 Hz 대역폭을 사용합니다. 사전 지정한 16/64픽셀 질의의 평균과
공분산은 별도 전체 FFT 계산과 상대 L2 오차 **1.6×10⁻¹⁴** 이내로
일치합니다. 한 프로세스에서 기존 해석 질의는 0.232/3.774초, 전체 FFT는
2.135/2.589초가 걸렸습니다. 국소 실행 시간이며 일정한 속도 우위나 네이티브
처리량을 뜻하지 않습니다. 새로운 Fourier 근사는 추가하지 않았습니다.
두 질의 집합에서 이상적 법선 평균과의 차이는 0.0168%/0.802%입니다.
이는 모델 재현성 대조이며 기록된 지도의 정확도 개선이 아닙니다.

## 남은 관측 검증

형상과 반사율은 호출자가 제공하는 가설입니다. 실제 래스터화, 다중 경로,
원본 유한 정밀도·난수 효과와 네이티브·실물 장치 보정은 이 연산자에 포함하지
않습니다. 조건부 산란원 모멘트는 랜드마크·자세 공분산이나 보정된 영상 우도가
아닙니다. 항법·DVL 평균을 별도의 소나 정보로 사용하지 않습니다. DVL 거리
불확실성은 여전히 미확정입니다. 기존 [병진 영상 경계 실패](../sonar-translated-shadow-20261031/README.ko.md)와
전체 지도는 그대로 보존합니다.

다음은 원본 입력의 전력·가림 예측, 미지 반사율, 미확정 고도각과 상관
불확실성을 검증하는 단계입니다. 적합과 네이티브 융합에 앞서 확인해야 합니다.
이미 검토한 이 장면은 개발용 근거입니다. 유용한 지도 주장에는 독립 장면과
실제 DVL 잠금 손실·미장착 조건의 이득이 필요합니다.

## 재현

NumPy와 POSIM-SLAM을 설치한 뒤 이식 가능한 검사를 실행합니다.

```sh
python docs/diagnostics/sonar-source-local-power-20261031/verify.py
```

저장한 법선 전체를 확인하고 두 전력 모멘트 대조를 다시 계산합니다.
`run_controls.py --source POSIM_SOURCE --sdk OPENCV_SDK --output NEW_DIRECTORY`는
기록한 Apple Silicon·OpenCV 배치로 원래 C++ 함수를 다시 실행합니다. 컴파일러와
기존 SDK가 필요하며 다운로드나 SDK 변경은 수행하지 않습니다.
`normal_reference.cc`와 `benchmark_moments.py`가 기준 함수 실행·벤치마크
절차를 보존합니다. [프로토콜](protocol.json)은 새 측정에 앞서 작성했으며
해시 목록은 전체 입력·출력과 공개 코드를 연결합니다.
