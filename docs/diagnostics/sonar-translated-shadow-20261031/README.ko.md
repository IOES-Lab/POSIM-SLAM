# 병진 시점 변화에서의 그림자 경계 관측

[English](README.md)

[횡이동 검사](../sonar-translated-view-20261031/README.ko.md)의 원본 193프레임과
IMU·DVL·압력 항법 상태 286개를 그대로 사용한 진단입니다. 네이티브 제약을
추가하기 전에 기존 영상 영역 해석을 검토합니다. 원본 입력·센서·SDK·잡음·지도
허용 기준은 바꾸지 않았습니다.

![실제 네이티브 현장과 전체 조건부 관측](full-cloud-comparison.png)

각도 중앙값 배경은 조건부 관측 **9,617개**, 전체 표면 RMSE **0.06669m**를
생성하며 진단용 10cm 기준을 넘는 점은 **1,157개**입니다. 균일 물리 평면 배경은
**10,424개**, RMSE **0.08219m**, 10cm 초과 **1,725개**입니다.
[각도 중앙값](angular_median-all.ply)과 [물리 평면](physical_plane-all.ply)의
전체 PLY에 모두 보존합니다. 이들은 서로 연관된 관측 가설이며 서로 다른 실제
랜드마크가 아닙니다. 가까운 표면과의 오차가 작다는 사실만으로 물리적 동일성이나
SLAM을 인정하지 않습니다.

앞쪽 밝은 반사·어두운 영역·배경 복구를 갖춘 쌍은 1,005개와 534개입니다.
RMSE는 0.04789m와 0.05637m, 10cm 초과는 60개와 47개입니다. 이 프레임들의
첫 블록 기준 관측 방위 변화는 별도 평가에서 62.69°와 60.64°입니다. 쌍을
찾았다는 사실이 여러 시점의 같은 물리적 점을 식별해 주지는 않습니다. 다른
출력도 모두 남기며, 두 배경의 출력 모집단이 달라 어느 쪽도 개선된 지도로
합격시키지 않습니다. 항법은 같은 0.04791m 기준 상태이며 이 진단은 음향 제약으로
자세를 갱신하지 않습니다.

## 구성과 실제 입력

기존 연속 원뿔의 평균 거리 적합으로 DVL 97패킷 중 자세가 있는 96개의 평면을
구합니다. 초기 DVL 한 패킷에는 네이티브 자세가 없습니다. 각 소나 프레임은
최대 1.01초 이전 평면만 사용하며 초기 두 프레임은 지원되지 않은 상태로
남깁니다. 원본 DVL 거리 분산은 제공되지 않습니다. 정적 보정 기록이 움직이는
비평면 지형에서의 외삽이나 자세와 공유하는 불확실성을 검증해 주지는 않습니다.

두 대조군은 같은 5표본 중앙값, 8dB 감소, 거리 3표본·수평 3빔·최소 면적 조건과
0.15m의 앞뒤 반사 확인 구간을 사용합니다. 물리 배경은 공개된 소스별 유한 표면
전력 연산자와 프레임별 공통 로그 전력 이득을 사용합니다. 어두운 영역만으로
가림을 확인할 수는 없습니다. 공선 관계식에는 실제로 대응하는 가림 모서리와
해저 그림자 끝점이 필요하며 임계값으로 얻은 픽셀 경계가 그 쌍임을 보장하지 않습니다.

거리 15m·599×256 소나, 수직 광선 256개와 명시적 하향 35° 검사 장착은
그대로입니다. IMU·압력·DVL은 실제 원본 스트림이고 Ping은 없습니다.
현장 RGB는 상위 기록의 같은 네이티브 참고 렌더링이며 안개·흡수만 껐습니다.
조명·집광무늬·입자·파도는 다른 위상으로 남습니다. 실제 센서 RGB의 시야는
2m이며 입력으로 사용하지 않습니다. 기체·소나·카메라 방향, 전체 공통 높이 범위,
파랑에서 빨강으로 변하는 Turbo 색상과 64pt² 점 크기로 모든 출력을 보여 줍니다.
회색 메시는 평가용 기준입니다. 원본 구성 단계에 장면·RGB·정답 자세를 넣지 않습니다.

## 알려진 기하의 평균 영상 대조

![별도의 이상적 평균 영상과 기하 모서리 대조](mean-boundary-control.png)

별도 수치 대조는 알려진 높이 0.45m 상자, 이상적인 수평 해저와 미리 정한
세 시각의 정확한 자세를 사용합니다. 조건부 평균 영상에 스페클이나 자세 잡음은
없습니다. 실제 센서 수집이나 추정기 입력이 아닙니다. 실제 기하 모서리와
해저 끝점의 12쌍을 주면 부동소수점 정밀도로 원래 모서리를 복원합니다.

평균 연산자는 이상적인 교차점·법선을 사용하고 네이티브 래스터화·법선 계산·다중
경로는 제외합니다. 이 수치 대조로 네이티브 렌더러나 상용 소나를 보정한 것은 아닙니다.

같은 평균 영상에 기존 영상 경계 규칙을 적용하면 조건부 점 74개와 쌍 관측
13개가 나옵니다. 세 번째 시점에서는 쌍을 얻지 못합니다. 쌍 관측 중 두 점은
알려진 상자 표면 밖으로 10cm 넘게 벗어나며 최대 오차는 0.11406m입니다.
74개 전체에는 그런 점이 10개이고 최대 오차는 0.66153m입니다. 쌍 관측의
높이 중앙값은 0.38482m와 0.38991m입니다. 이는 모서리 가설점의 기술 통계이며
물체의 최대 높이 추정값이 아닙니다. 실제 표면과의 거리를 별도 기하 검증으로 사용합니다.

2×2 수치 대조는 빔 사이 혼합과 중앙값 처리를 각각 제거해 봅니다. 거리 응답과
원래 광선·거리 격자는 유지합니다. 두 시점 모두 각 경우에 10cm를 넘는 쌍 관측이
남고 세 번째는 여전히 관측 불가입니다. 어느 단계 하나를 끄는 것으로 관측 정의가
해결되지 않습니다. 유한 개구·거리 응답·윤곽 모양·쌍 대응의 모든 영향을 따로
분리한 대조는 아닙니다. 실제 센서 물리나 기록된 검출기를 바꿀 근거로 사용하지 않습니다.

다음 관측 모델은 유한 물체·해저의 전력과 가림을 예측하고 미결정 고각과
거리·평면·자세의 상관 불확실성을 유지해야 합니다. 고정 높이 보정이나 또 다른
고정 XYZ 해석을 이 결과로 정당화하지 않습니다. 공개 `SurfacePowerModel`과
기존 결합 표면 전송 구현을 출발점으로 삼되, 네이티브 반영에는 사용하지 않은
시점의 물리적 지지와 실제 DVL 상실·부재에서의 기여가 추가로 필요합니다.

## 보존과 재현

통합 소스는 POSIM #6/#31–36을 포함한 `ffecee9b`이며 원래 PR들은 미병합입니다.
수집 시점 앱 `06ad1d2b`와 라이브러리 `7f485964`는 그대로 기록합니다.
공개 도우미는 `dcdbda2`에서 선택했습니다. 비공개 생성기 해시는 보존하며 앱
구현을 복사하지 않습니다. 상위 기록에 원래 소스·실행 파일 추적, 전체 원본 목록,
지형·Orca5 자산 출처와 제삼자 고지가 있습니다.

큰 JSON은 gzip/XZ로 무손실 압축하고 원래 바이트 해시를 보존합니다.
모든 영역·관측 불가 사례·점 메타데이터·전체 PLY·평가를 남깁니다. 원본 전체는
외장 디스크에 한 벌만 두며 이 이동 가능한 기록에는 원본 세 프레임을 포함합니다.
POSIM-SLAM과 진단 의존성을 설치한 환경에서 실행합니다.

```sh
python docs/diagnostics/sonar-translated-shadow-20261031/verify.py
# 보존한 원본 전체에서도 추출을 다시 확인하려면:
python docs/diagnostics/sonar-translated-shadow-20261031/verify.py --raw-root /path/to/record/inputs
```

검증기는 모든 평면·점·오차·전체 PLY, 선택한 원본 추출, 모든 이상적 모델 대조와
12개의 정확한 모서리를 다시 계산합니다. 센서 수집이나 네이티브 항법을 다시
실행하지는 않습니다. 지도·물리적 대응·결합 불확실성·항법 기여·설치 검증은
합격하지 않은 상태입니다.

Matplotlib과 Pillow를 추가 설치하면 `render.py`로 두 그림을 공개 데이터에서
다시 그릴 수 있습니다. 이상적 평균 영상은 명시된 기하로 다시 계산합니다.
