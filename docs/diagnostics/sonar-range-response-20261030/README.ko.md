# 소나 거리 응답과 파워 관측의 상관관계

[English](README.md)

거리 응답 모델이 저장된 단일 반사체 네이티브 출력을 설명하며, 여러 반사가
합쳐지는 경우의 평균 파워를 실제 고정 평판 입력과 대조했습니다.
약한 반사 영역의 보정은 미완료입니다. 이번 결과는 소스 모델 진단이며
소나 지도 검증 완료가 아닙니다.
POSIM 소스 `7afd71e7b7a1a13eca8c4b8deb9c6e8461285cd5`는 현재 엔진 main과
#6·#31–36을 별도 브랜치에 통합한 상태입니다. 해당 PR들은 열려 있습니다.
설치 SDK, 네이티브 추정기, 선택된 실행 요인과 지도 수용 기준은 변경하지 않았습니다.

`PosimRangeResponse`는 생산자의 정규화한 주기적 Hamming 창, 주파수 표본과
원래 길이 FFT를 계산합니다. 반사체 거리, 복소 진폭 분산과 빔 혼합값이 입력입니다.
독립인 원형 복소 Gaussian 산란에 대해 전달 행렬 H를 사용하면
`C = H diag(v) H*`, `E[P_i] = C_ii`, `Cov(P_i, P_j) = |C_ij|²`입니다.
평균은 반사체 32개씩 계산하고, 결합 모멘트는 선택한 출력 픽셀 64개로 제한합니다.
입력 기하에 따른 소스 모델의 값이며, 영상에서 기하·반사체 대응·자세 불확실성을
추정하는 API는 아닙니다. GPU 반올림·포화와 실제 장비 보정은 별도 확인이 필요합니다.

소스의 원본은 `20 log10(|z|)`이므로 파워는 `10**(dB/10)`입니다.
무반사는 전력 0으로 유지합니다. 거리 응답, 빔 혼합, 전파 감쇠와 입사각을 포함합니다.
소스의 레이별 국소 법선 z는 입사각의 코사인입니다. 첫 비공개 평판 계산에서는
이 항을 빠뜨렸으며, 그 실패와 데이터를 외장 디스크에 보존합니다.
모델에 맞추기 위해 생산자를 수정하지 않았습니다.

## 실제 대조 결과

- 저장한 단일 반사체 양의 출력 32개는 홀수·짝수 길이 598/599, 두 시드와
  거리 여덟 개를 포함합니다. 창 응답에 대한 정규화 복소 잔차의 최댓값은
  약 `1.08e-4`입니다. 정답 중심의 탐색 구간 없이 전체 물리 거리를 탐색했을 때
  최대 거리 오차는 `6.10e-7 m`였습니다. 알려진 수치 연산 대조이며 실제 소나나
  장면 정확도를 뜻하지 않습니다. 범위 밖 출력 네 개는 계속 0입니다.
  전체 원본 배열은 [소스·거리 격자 기록](../sonar-pr31-36-20261030/README.md)에 있습니다.
- 변경하지 않은 #35 WGPU 검사는 원본·미리보기 125쌍과 정상 서버 종료를
  통과했습니다. 추가 관찰기는 원본·법선·렌더러 거리 각각 180프레임을 보존하며
  세 시각 집합이 같습니다. 이 32빔·32레이·10 m·900 kHz 시험은 수직 인덱스
  0/10/20/30을 계산합니다. 데모 설정과 구분합니다.
- 별도 대조는 실제 데모의 센서 내부 설정을 복사합니다. 256빔·수직 256레이,
  120° × 20°, 700 kHz, 대역폭 29.9 kHz, 음속 1500 m/s, 15 m,
  거리 표본 599개, 레이 간격 1, 2 Hz입니다. 원본 52개·법선 52개·거리 25개 중
  시각이 같은 25묶음을 확보했습니다. 전체 스트림이 모두 동기화되거나 손실 없이
  수신됐다는 검증은 아닙니다. 소유 프로세스 두 개 모두 강제 종료 없이 0으로
  끝났습니다. 차량·월드 대신 정지 순방향 센서와 평판을 사용하므로 BlueROV
  운항이나 환경 효과 검사는 아닙니다.
- 평가 구간의 렌더러 기하는 정확히 일정합니다. 실제 거리와 기존 RGB8 법선으로
  파워를 예측하고, 공통 양의 진폭 배율 하나만 맞췄습니다. 이 렌더러 자료는
  평가 입력이며 SLAM 추정기에 전달하지 않습니다.

| --- | ---: | ---: | ---: | ---: |
| 32빔, 평판 4.000 m | 14.543 mm | 0.309 | 0.204 | 0.700 |
| 32빔, 평판 4.001 m | 14.498 mm | 0.337 | 0.229 | 0.698 |
| 데모 내부 설정, 평판 4.000 m | 4.964 mm | 0.208 | 0.190 | 0.425 |

파워 잔차는 같은 25회 측정 평균에 대한 전체 영상의 상대 L2 값입니다.
이상 기하·렌더러 비교에는 같은 관측을 사용합니다. 두 센서 설정은 여러 값이
달라지므로 수직 레이 수만의 효과를 분리한 비교가 아닙니다. 렌더러의 평판 수직
방향 최대 절대 오차는 작은 시험에서 40.561/40.248 mm, 데모 내부 설정에서는
18.676 mm입니다. 오프셋 보정이나 오차 0 목표를 설치하지 않았습니다.

이상적인 독립 측정 Gaussian 모델에서 한 픽셀의 25회 평균 상대 RMS는
`1/sqrt(25)=0.2`입니다. 참고 크기이며 위 잔차의 신뢰 구간이나 허용 기준은 아닙니다.
표의 상관계수는 주어진 소스 기하로 계산한 값이며 현장에서 추정한 상관계수가
아닙니다. 서로 상관된 표본을 독립 랜드마크 근거로 셀 수는 없습니다.

약한 꼬리 영역은 미검증입니다. 렌더러의 모든 반사 거리가 8.162 m 미만인
상황에서 10–15 m의 전체 51,200셀 평균 파워는 측정 0.29845·예측 0.06456으로
4.623배 차이가 있습니다. 이 값은 시험 단위와 맞춘 공통 배율을 사용합니다.
전체 L2 결과는 강한 반사에 지배되므로 이 영역까지 검증하지는 못합니다.
소스의 고정소수점 누적은 원인 후보이며, 같은 입력을 사용한 인과 대조가 필요합니다.
수치 잡음 오프셋이나 새 측정 신뢰도를 설치하지 않았습니다.

이 보정 대조는 안개·입자·해저 집광무늬·파도가 없는 고정 평판입니다.
거리 표본 599개와 전체 256 × 256 렌더러 격자를 그림이나 데이터에 보존합니다.
렌더러 기하는 검사용 기준이며 생성한 SLAM 점군이 아닙니다.

광학 가시거리 2 m인 실제 Orca5 환경을 유지합니다.

## 실제 지형에 대한 의미와 한계

정규 Orca5 95프레임의 모든 빔을 최적의 단일 반사체 파워 형상과 비교했습니다.
24,320개 형상을 모두 보존하며 정규화 잔차 중앙값은 0.813입니다.
앞선 평판의 비어 있지 않은 형상 2,624개에서는 중앙값이 0.272입니다.
빔 전체에는 여러 반사가 포함될 수 있으므로 모든 국소 점 특징이 잘못됐다는
결론은 아닙니다. 강도 픽셀을 XYZ로 바꾸기 전에 국소 관측의 근거와 지속성을
검사할 이유입니다. 전체 지형 원본은 외장 디스크 한 곳에 있으며,
`all-profile-fits.npz`는 모든 형상의 적합 결과를 보존하고 원본 영상을 복제하지 않습니다.

다음은 센서 입력만 사용한 국소 패치 대응을 독립 시점에서 확인하는 단계입니다.
거리 응답, 파워 상관관계, 자세 불확실성과 모호한 수직 각도를 유지해야 합니다.
기존 연구도 유효한 운동 제약과 충분히 구속된 3D 랜드마크를 구분합니다
([Westman 외, 2018](https://www.cs.cmu.edu/~kaess/pub/Westman18icra.pdf),
[Westman·Kaess, 2020](https://www.cs.cmu.edu/~kaess/pub/Westman20joe.html)).
새 현장 요인, 점군 개선이나 학술적 독창성을 주장하지 않습니다.
최소 낙관적 3시그마 약 0.493 m인 기존 실패도 유지합니다.
IMU·압력 기본값, DVL/Ping 배제와 전체 지도 내보내기는 계속 필요합니다.
유용한 소나 지도, 실제 DVL 끊김·미장착 이득, 설치형·운영체제, VRX와 WAM-V
측량 검증은 미완료입니다.

## 재현과 보존

해당 POSIM-SLAM과 NumPy 환경에서 `python verify.py`를 실행합니다.
네이티브 전달 응답, 작은 시험의 전체 입력 검사와 파워 예측을 다시 계산합니다.
고해상도에서는 전체 해상도의 25프레임 충분 통계와 완전한 대표 입력 한 장으로
모멘트를 다시 계산합니다. 수집이나 원본 지형 추출을 다시 실행하지는 않습니다.
`plot_response.py`는 Matplotlib으로 그림을 만듭니다. 소스·네이티브 식별 해시를
보존합니다. 새 수치 검사 여섯 개는 독립적인 닫힌 형태의 창 응답, 주기, 혼합,
범위 제한, Gaussian 파워 공분산과 잘못된 입력을 다룹니다.
깨끗한 SDK 검사 결과는 549개 중 527개 통과·선택적 환경 22개 제외입니다.

전체 수집, 비공개 수집 코드, 시작 실패와 입사각을 빠뜨린 대조는 ExternalHDD
한 곳에 남깁니다. 공개한 작은 시험 배열은 손실 없이 중복을 제거했습니다.
큰 시험은 전체 원본을 두 Git 저장소에 복제하지 않도록 전체 해상도 충분 통계를
사용합니다. 거리 XYZ에는 PointCloud2의 무관한 필드가 포함되지 않습니다.
첫 고해상도 사전 검사는 SDF 저장 중 필수 `gz:` 접두어를 잃었고,
두 번째는 초기화를 고정 5초로 가정했습니다. 모두 정상 정리 후 실패했습니다.
생성기는 접두어를 보존하고 수집기는 별도의 30초 시작 한도 안에서 실제 첫 프레임을
기다립니다. 운용 검사는 그대로 30초 이내 같은 시각의 25묶음입니다.
첫 격리 단위 시험은 커밋된 tools/native 의존 파일을 빠뜨렸습니다.
의존 파일을 복원했으며 시험 조건은 바꾸지 않았습니다.
GitHub Artifact 다운로드, LIVE·러너 재시작, SDK 교체나 새 공급자 ABI는 사용하지 않았습니다.

첫 Linux CI는 수치 검사를 통과했지만 저장한 해시 목록에 로컬 Python 캐시가
포함된 것을 발견했습니다. 목록을 Git 관리 보고서 파일로 다시 만들고 깨끗한
아카이브에서 검사합니다. 생성한 바이트코드는 진단 입력에 포함하지 않으며,
측정 검사나 수치 한도를 제거하지 않습니다.
