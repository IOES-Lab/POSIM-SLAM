# 반사체 후보와 전체 영상의 일치 검사

[English](README.md)

센서만으로 반사체 후보를 만들고, 남은 현장 입력·관측 모델의 일치 조건을
확인합니다. 새 형상은 **지도에 채택하지 않습니다**. 여러 시점이 겹치고 영상
점수가 좋아져도 잘못된 형상이 생깁니다. 네이티브 갱신·지도 합격·센서 잡음
변경·원본 소스 PR 병합은 없습니다.

![기록된 카메라와 물체 가설의 전체 표본](object-camera-comparison.png)

기록된 카메라와 같은 투영·잘라낸 범위에 기준 160개, 선택 가설 240개의 물체
표본을 모두 표시합니다. 주황색은 소나·동일 장착 RGB의 35° 하향 방향,
파란색은 차량 RGB 방향입니다. 현장 확인용 RGB는 안개·흡수를 끄고,
조명·해저 집광무늬·입자·파도는 다른 위상의 상태를 유지합니다.
실제 추정 카메라의 가시거리는 2 m입니다.

![측정되지 않은 해저를 포함한 유한 장면 전체](complete-scene-comparison.png)

전체 그림은 각 **3,939/4,019개** 표본과 보이지 않은 면도 유지합니다.
64 pt² 점과 같은 파랑→빨강 Turbo 높이 범위를 사용합니다. 흐린 해저는
외삽한 사전 형상입니다. 전체 장면은 RGB와 같은 관측 방향의 직교 투영,
물체 확대는 기록된 카메라의 원근 투영입니다. 두 PLY에 모든 표본을 보존하며,
측정된 소나 랜드마크로 해석하지 않습니다.

## 원본 전력의 역추정

[앞서 고정한 유한 장면](../sonar-partial-scene-fit-20261031/README.ko.md), 원본
소나 여덟 프레임과 항법 평균을 재사용합니다. 통합 `ffecee9b`는 현재 #6·#31–36을
모두 포함합니다. 원격 커밋과 main을 다시 확인했고 변경·병합은 없습니다.
IMU·압력·DVL과 15 m, 영상 599×256·광선 256×256 설정을 유지합니다.
원본 기록을 추가 복제하지 않습니다.

`sonar_birth`는 같은 소스 법선·Hamming 자기상관·원래 길이의 Fourier 변환으로
전체 영상의 후보 예측 평균을 계산합니다. 상쇄로 생길 수 있는 작은 부호값과
연산 오차 범위를 보존하고, 기존의 정확한 양수 합산 연산자로 질의 예측을
검사합니다. 원본의 약한 반사·0을 잘라내지 않습니다. 영상 전체에 공통인 총전력
배율과 같은 5×5 국소 전력 평균으로 학습 다섯 시점의 초과 성분 392개를 찾습니다.
40개 성분이 제한된 후보 탐색에 들어갑니다. 대비·크기 설정은 후보 생성값이며
보정된 오경보 확률이 아닙니다.

선택 영역의 모든 픽셀에서 명목 ±10° 고도각을 펼칩니다. 0.2 m 검색 셀
8,534개 중 337개에 최소 세 시점이 겹칩니다. 같은 시점의 픽셀·영역을
중복해도 시점 수는 늘지 않습니다. 새 유한 상자 후보 세 개는 5/4/4시점의
지지를 얻습니다. 바닥은 기존의 불확실한 DVL 평면 사전 가설입니다.
그림자 높이·정답 메시·정답 자세·RGB로 초기화하지 않습니다.

같은 원본 질의에서 11개 전체 장면을 비교합니다. 기준 장면, 기존 단일 시점
후보의 면을 실제로 제거한 장면, 새 위치별 높이 세 가지입니다. 학습 자료만으로
하나를 선택합니다. 87.2초 동안 복합 질의 점수는 **1883.532→1843.119**이며,
차순위는 1843.632입니다. 추정 결과를 고정한 뒤 미사용 시간 시점의 점수는
**1867.861→1780.747**로 줄지만 개별 시점은 엇갈립니다. 질의 전체 공분산을
유지합니다. 같은 개발 장면이므로 독립 장면이나 공통 자세·지도 신뢰도의
검증으로 해석하지 않습니다.

고정 후 형상 평가에서 새 80개 표본의 표면 RMSE는 **15.24 cm**, 기존 진단값
10 cm 초과는 44개입니다. 대부분 새 물체보다 해저·기존 형상 주변에 놓입니다.
물체 표본 전체의 RMSE는 **4.95→9.68 cm**, 장면 전체는 **13.09→13.13 cm**입니다.
전체 표본 수에는 변하지 않은 해저 사전 형상의 영향이 큽니다. 결과를 개선하려고
표본을 제거하지 않습니다.

## 커널 일치와 현장 일치의 구분

선택 후 양수 합산으로 모든 원래 픽셀을 검사합니다. FFT 상쇄나 평균 하한값을
사용하지 않습니다. 전체 영상의 학습·미사용 점수도 잘못된 후보를 선호합니다.
각각 **2,262,453→1,860,263 / 1,419,887→1,121,950**입니다. 일부 질의 선택만으로
실패를 설명할 수 없으며, 고정된 선택은 바꾸지 않습니다.

이미 보존된 전체 평가 장면 격자에서 항법·정답 자세의 전체 영상 잔차 RMS는
27/81/88번에 각각 **2.61/5.24/44.54**, **2.35/2.66/45.13**입니다. 평가용 형상과
40 ms 정답 보간은 추정에 사용하지 않으며, 렌더링 표본·촬영 시각의 정확성은
미확정입니다. 실제 캡처에 쓰인 해저 DAE와 평가 해저는 꼭짓점 16,384개와
삼각형 32,258개가 정확히 같습니다. 여덟 항법 평균 자세의 명목 광선은 위쪽을
향하지 않습니다. 이 검사로 실제 렌더러 거리 격자·센서 자세·촬영 시각까지
보증하지는 않습니다.

기존 GPU 커널 512회 기록을 원래 질의 64개에서 **153,344개 전체 픽셀**로 확대해
검사했으며 모두 통과합니다. 88번 평가 격자를 입력한 별도 공개 C ABI 64회
대조군도 전체 픽셀을 통과합니다. 두 경우 모두 사전에 정한 Bonferroni 양측
Gamma 범위와 전체 α=.01을 사용하며, 복소 Gaussian 산란과 프레임별 독립성을
조건으로 합니다. 실제 로드한 바이너리 SHA를 보존합니다. 입력한 평가 격자는
실제 렌더러 격자와 구분하며, 새 렌더러·월드·SDK는 실행하지 않습니다.
이 대조군에서는 추가 센서 생산 코드 수정의 근거가 없습니다.

**다음:** 같은 현장 프레임의 실제 거리 격자 입력·센서/차량 자세·촬영 시각을
대조합니다. 장면→광선 표본·자세·시각의 불일치를 먼저 해결한 뒤 새 매퍼 팩터를
추가하고, 자세·지도·반사율의 공통 불확실성을 다룹니다. 반복 시점의 겹침만으로
물리적 반사체를 채택할 수 없습니다.

## 재현과 보존

NumPy·SciPy 진단 의존성을 설치한 라이브러리에서 실행합니다.

```sh
python -m unittest discover -s tests -p test_sonar_birth.py
python -m unittest discover -s docs/diagnostics/sonar-reflector-birth-20261031 -p test_full_image_audit.py
python docs/diagnostics/sonar-reflector-birth-20261031/verify.py --full-image
```

검증기는 새 제한된 임시 경로에서 후보 생성, 모든 대안의 원본 전력 점수,
최종 공분산·미사용 예측·실패 형상 전체와 PLY를 다시 계산합니다. 전체 모드는
보존 입력으로 영상 전체·평가 장면·커널 대조군을 재계산합니다. CI에는 GPU나
아티팩트 다운로드가 필요하지 않습니다. 원본 해시는 정확히 유지하고 float64
전력·float32 소스 법선·기하 연산 허용 범위를 물리 잡음·지도 합격과 구분합니다.

기존 그림 도구에 기록·가설·제목 인자를 추가했습니다. 기존 PNG 두 개와 영수증은
바이트 단위로 같고 도구·목록 해시만 갱신합니다. 코드·기록은 Apache-2.0이며,
기존 Orca5 MIT 자산 고지를 유지합니다. 새 제3자 의존성·설치 SDK 변경·LIVE나
러너 재시작은 없습니다.
