# 소나 고도 호를 이용한 대응과 관측 동작 검토

[English](README.md)

이 오프라인 대조군은 [실제 검사 장면의 원본](../sonar-inspection-scene-20261031/README.ko.md), 보정된 POSIM 통합 `ffecee9b`, 현재 #6/#31–36을 재사용합니다. 센서·네이티브 최적화기·provider ABI·설치 SDK를 바꾸지 않습니다. 두 방식 모두 소나·RGB를 사용하지 않은 IMU/DVL/압력 항법 자세를 고정해 사용합니다. 자세 불확실성은 전파하지 않으므로 명목상 대응과 조건부 점 복원 진단입니다.

## 같은 특징, 다른 대응 방식

기존 원본 영상 변환(20–90 dB, 5×5 가우시안 필터)에 기본 A-KAZE를 적용하면 재생 가능한 93프레임에서 특징 2,670개를 검출합니다. 원본과 앞선 시작 구간은 그대로 보존합니다. 두 방식은 OpenCV 4.10.0 연구용 검출의 동일한 픽셀·기술자를 사용합니다.

- **기술자 매칭:** Hamming 거리와 기존 0.8 최근접 비율을 적용한 상호 매칭입니다.
- **고도 호 투영:** `project_return_arc()`로 첫 관측의 가능한 고도 ±10° 전체를 인과적인 항법 자세에 따라 투영합니다. 2픽셀 안에 서로 유일한 후보만 연결합니다. 모든 기존 투영에서 5픽셀보다 먼 특징은 새 추적을 시작할 수 있고, 모호한 후보는 미정으로 둡니다. 관측이 끊긴 추적은 최대 2초, 데이터베이스는 300개로 제한합니다. 픽셀 범위는 진단용 설정이며 보정된 확률 기준이 아닙니다.

기하 계산은 외관 기술자 대신 A-KAZE 특징을 기하적으로 대응하는 [Westman 외, ICRA 2018의 IV절·Algorithm 1](https://www.cs.cmu.edu/~kaess/pub/Westman18icra.html)을 참고합니다. 이번 대조군은 상호 유일성과 제한된 추적 수명을 적용합니다. 논문의 전체 최적화기 구현이나 새로운 연구 기여를 주장하지 않습니다. [2020년 퇴화 대응 연구](https://www.cs.cmu.edu/~kaess/pub/Westman20joe.html)도 대응점 신뢰성과 약하게 구속된 복원을 구분합니다. 원본 구현 코드는 복사하지 않습니다.

관측이 세 개 이상인 추적마다 처음 세∼여덟 관측만으로 점 후보 하나를 만듭니다. 기존 고도 초기값 아홉 개와 최대 열두 번 계산을 사용합니다. 진단용 표준편차는 0.0250836 m·0.00821331 rad를 유지합니다. 측정 비용으로 결과를 고른 뒤 별도 평가에서만 실제 형상과 시뮬레이터 정답을 읽습니다. 네이티브 제약이나 합격 지도를 추가하지 않습니다.

208·63개 점과 이상점, 아홉 초기값의 결과를 모두 보존합니다. 점은 64 pt²이며 전체 높이 범위를 포괄하는 Turbo 색을 공유합니다. 네이티브 장면은 기록된 28.01초 차량 자세와 차량·센서 방향을 보여 줍니다. 평가용 전경에서만 안개·흡광을 끄고 파도·수중 조명·입자·해저 집광무늬를 유지합니다. 입자와 파도 위상은 다릅니다. 원본 RGB는 시정 2 m이며 방법에 입력하지 않습니다. 같은 등각 방향을 사용하고 화면 범위는 각각 맞춥니다. 시각을 맞춘 원본 센서 영상은 앞선 기록에 있으며 원본이나 비교 RGB를 중복 보관하지 않습니다.

## 미사용 시점과 한계

점 생성 구간에서 2초 이상 지난 관측은 기술자 방식의 208개 추적 중 9개에 70개가 남습니다. 예측 형상 안이 62개, 밖이 8개입니다. 형상 안의 거리·방위각 RMSE는 0.0270 m·0.0141 rad입니다. 고도 호 방식은 63개 중 9개 추적에 22개가 남고, 형상 안 21개·밖 1개이며 형상 안 RMSE는 0.0318 m·0.0344 rad입니다. 후속 관측이 없는 추적과 형상 밖 예측도 전체 개수에 남깁니다. 대응에는 복원된 점 대신 첫 관측의 호를 사용하므로 명목상 연결을 통과해도 같은 3차원 반사체임을 입증하지 못합니다. 표면 오차 중앙값 감소만으로 항법·지도 개선을 인정하지 않습니다.

고도 표본을 65개에서 257개로 바꾸면 한 프레임의 대응이 달라집니다. 이 불일치를 그대로 보존하며, 표본 사이 선분으로 연속 곡선의 거리를 보증하지 않습니다. 자세 불확실성, 물리적 대응점, 연속 호의 범위, 유용한 3차원 관측성은 미해결입니다. 점 지도는 합격으로 인정하지 않습니다. 설치 SDK의 `NativeOpenCV`에는 A-KAZE 함수가 없으며 이를 호출했던 첫 비공개 사전 검사의 실패도 보존합니다. 성공한 비교는 기존 별도 연구용 Python을 사용하며 SDK·ABI 우회 수정은 없습니다.

## 관측 동작 계산

별도 이상적인 점 반사 계산은 같은 장착 형상·진단 표준편차와 정확한 자세 16개를 사용합니다. 낙관적인 측정 정보 계산이며 실제 차량 실행이 아닙니다. 거리 2.5 m에서 정지 관측은 세 위치 방향 중 두 방향만 구속합니다. 차량 방향을 ±15° 바꾸면 최대 불확실성 방향의 위치 3σ는 0.283 m이고, ±45°·±55°에서는 0.103·0.0882 m입니다. 아래로 20.1° 기울어진 장착과 회전하는 장착 위치 때문에 차량의 수평 회전은 소나 축 주위의 순수한 수평 회전과 다릅니다. 차량 롤 ±15°에서는 0.103 m, 롤 ±20°에서는 0.0775 m입니다. 거리 5·10 m에서 롤 ±15°의 값은 0.205·0.411 m입니다. 지원 범위를 벗어난 관측은 별도로 남깁니다. 공유 자세 불확실성, 실제 특징의 지속성, 센서 모델 오차는 추가 한계입니다.

따라서 다음 최적화기 수정 전에 기존 경유점 방향 지정으로 근거리 관측을 시험하고, 필요하면 롤 변화를 추가로 검토합니다. 설치 바이너리는 ArduSub 4.5.7(`30257f01`)과 확장 수동 입력 심벌을 확인합니다. 해당 버전의 [조이스틱 코드](https://github.com/ArduPilot/ardupilot/blob/30257f01/ArduSub/joystick.cpp)·[Guided 제어기](https://github.com/ArduPilot/ardupilot/blob/30257f01/ArduSub/mode_guided.cpp)는 현재 개발 버전과 입력 배율이 다릅니다. 실제 롤 응답, 경로 여유, 상실·복구, 지도 이득은 분리된 네이티브 시험이 필요하며 이 기록에서는 롤 명령을 실행하지 않습니다.

공개 POSIM-SLAM 소스와 NumPy 환경에서 `python verify.py`를 실행합니다. 독립적인 Hamming 매칭과 두 방식의 전체 대응 이력을 재현하고, 표본 수 불일치·모든 조건부 점·비용·미사용 관측 예측·이상적인 동작 정보를 검사합니다. `test_projective_assoc.py`는 모호성·중복 검출·순서 불변성·지원 구간 단절·영상 경계·수명·시각을 검사합니다. `replay_prepared.py`는 준비된 측정과 공개 라이브러리만 사용하며, `plot_comparison.py`로 그림을 다시 그립니다. 원본 전체와 공유 자산의 해시를 보존합니다. 앞선 소스·네이티브 지도·설치·플랫폼의 검증 범위는 그대로 구분합니다. 공유 Orca5 유래 자산의 [MIT 고지](../sonar-inspection-scene-20261031/Orca5-LICENSE.txt)를 유지합니다.
