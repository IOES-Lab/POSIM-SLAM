# 네이티브 소나 입력의 정확한 기록: 사전 대조

[English](README.md)

음향 기준 소스는 POSIM `ffecee9b`이며 원본 #6과 #31–36의 변경을 포함합니다.
별도 진단 소스는 실제 WGPU 호출에 선택형 기록기를 추가합니다. 렌더 시작·콜백의
노드 자세와 캡처 시각은 복제된 거리 스냅샷과 함께 계산 스레드로 전달됩니다.
원본 PR들은 미병합 상태입니다.
[소스·바이너리 식별 정보](source-identity.json)를 보존합니다.

실제 연결된 어댑터는 같은 바이너리 내부의 음향 함수를 직접 호출합니다.
따라서 외부 가로채기가 입력을 잡았다고 가정하지 않고 호출 지점에서 명시적으로
기록합니다. [호출 연결 증거](native-call-binding.json)와
[소스 스냅샷](source/sonar_native_trace.hh)을 확인할 수 있습니다.

## 전체 바이트 대조

원본 현장 기록을 복제하지 않고 기존 평가용 기준 거리 배열을 재사용합니다.
자세는 `offline_supplied_grid`로 표시한 가상 재생 정보이며,
**실제 렌더러 캡처가 아닙니다**.

- 기록을 끈 경우와 켠 경우의 256 × 599 복소수 영상 6개가 모두 바이트 단위로
  같습니다. 보존된 수정 전 네이티브 라이브러리를 새로 호출한 결과도 전체
  영상 6개와 일치합니다. 선택한 픽셀이나 평균 전력만 비교하지 않습니다.
- 기록된 입력 텐서 5개와 float32 계산 인자 10개가 주어진 입력 비트와
  같습니다. 차원, 프레임 번호, 시드와 메타데이터도 일치합니다.
- 정확히 4개 기록에 압축 전 합계 **11,210,144바이트**를 보존합니다.
  전체 복소수 출력이 독립적으로 계산한 영상 해시와 일치합니다.
  Gzip은 끝 식별자를 포함한 원래 기록 바이트를 그대로 보존합니다.
- 독립된 C++ 사례 16개는 비활성화·문맥 없음, 용량 제한, 잘못된 설정,
  큰 입력, 역순 시각, 동시 호출, 기존 파일 보존, 빈 출력, 계산 예외 전달,
  유한하지 않은 IEEE 값을 검사합니다. 손상 기록 3개도 거부합니다.
- 실제 Release 구성의 CMake 검사 `bounded_native_trace`가 통과합니다.
  원래 계산 인자, 반환 포인터, 예외와 스레드별 문맥을 유지합니다.
  예외에서는 미완성 진단 파일을 닫고 유효 기록으로 인정하지 않습니다.

## 독립 검증

NumPy가 있는 환경에서 실행합니다.

```sh
python verify.py
```

공유하는 유일한 입력은 고정 해시의
`../sonar-reflector-birth-20261031/native-reference/inputs.npz`입니다.
WWW-POSIM 모듈은 가져오지 않습니다. `c++` 컴파일러가 있다면 표준 C++17
검사 전체를 함께 컴파일하고 실행할 수 있습니다.

```sh
python verify.py --native-unit
```

플랫폼별 선택적 재빌드를 위한 실행 도구도 보존합니다. 선택한 공개 POSIM
소스, 이미 검증한 네이티브 의존성 빌드와 CMake 연결 입력이 필요합니다.
설치된 SDK는 읽기 전용 입력입니다. 네이티브 라이브러리나 SDK 압축 파일을
이 휴대형 검증 자료에 복제하지 않습니다.

## 다음 운영 검증

제한된 실제 캡처에서 진단을 켠 뒤, 전체 복소수 출력을 발행된 원시 영상·캡처
시각과 연결합니다. 기록한 렌더링 노드 자세에서 장면의 첫 교차 거리와 실제
렌더러 거리 배열을 비교합니다. 각도·래스터 표본, 자세·시각, 법선 민감도를
구분한 뒤 음향 생성기 수정이나 지도 요인 추가를 판단합니다.

이 재생 대조는 새 월드·렌더러 실행, SDK 교체, 네이티브 자세 갱신이나 지도
승인을 수행하지 않습니다. 기존의 잘못된 반사체와 현장 영상 불일치는
[전체 실패 기록](../sonar-reflector-birth-20261031/README.ko.md)에 보존합니다.
초기화, 유용한 지도, 실제 DVL 상실·부재, 설치 플랫폼, VRX와 이후 WAM-V
해저 측량 검증은 남아 있습니다.
