# 유한한 부분 장면의 역추정

[English](README.md)

기존 소스 관측 연산자를 재사용해 원본 소나 전력으로 공통 장면의 높이를
맞춥니다. 센서에서 얻은 두 반사체 후보와 유한한 해저 격자를 함께 다룹니다.
평가용 장면·정답 자세·RGB는 추정에 입력하지 않습니다. 고정된 항법 평균을
조건으로 한 오프라인 역추정이며, 합격한 SLAM 지도는 아닙니다.

![원래 RGB 카메라와 같은 투영으로 비교한 물체 가설](object-camera-comparison.png)

기록된 카메라 내부·외부 파라미터와 잘라낸 범위를 동일하게 적용합니다.
각 물체 가설의 160개 표본을 모두 표시합니다. 주황색은 소나·동일 장착 RGB의
35° 하향 방향, 파란색은 차량 RGB 방향입니다. 현장 확인용 RGB는 안개·흡수를
끄고, 조명·해저 집광무늬·입자·파도는 다른 위상의 상태를 유지합니다.
실제 추정 카메라의 가시거리는 2 m입니다.

![유한 장면 가설의 전체 표본 비교](complete-scene-comparison.png)

전체 그림에는 각 3,939개 표본을 모두 보존합니다. 외삽한 해저 사전 형상의
3,779개 표본과 보이지 않은 물체 면도 포함합니다. 카메라와 같은 관측 방향의
직교 투영이며, 현장 RGB의 원근 투영과 구분합니다. 두 그림 모두 64 pt²
점 크기와 같은 파랑→빨강 Turbo 높이 범위를 사용합니다. 전체 PLY에서
오차나 가시성을 이유로 표본을 제거하지 않습니다.

## 입력과 실제 역추정

POSIM 통합 소스는 `ffecee9b`입니다. 다시 확인한 #6·#31–36의 현재 커밋을
모두 포함하며 원본 PR은 미병합 상태입니다. [소스 검토](source-review.json)는
중복 생성·장착 자세, ROS 수명·원래 시각, 부분 행렬 타일, 약한 반사와 부동소수점
계산, 빈 영상, 물리 거리 격자의 담당 범위를 구분합니다. 추가 센서 생산 코드
수정의 근거는 없으며, 이번 역추정 코드는 POSIM-SLAM에 속합니다.

[높이 변화 기록](../sonar-height-diversity-fit-20261031/README.ko.md)의 학습 프레임
27/49/81/88/151과 미사용 시간 프레임 51/90/153을 재사용합니다. 원본 599×256
전력 격자, 15 m 범위, 256×256 광선, 소스 식별과 고정 질의 픽셀을 유지합니다.
원본 파일은 정확한 해시로 공유하고 복제하지 않습니다. 같은 개발 장면의
시점들이므로 독립 장면 검증으로 해석하지 않습니다.

기존 조건부 검출의 두 군집 11개·62개를 각각 유한한 직육면체로 초기화합니다.
이전 실험은 큰 군집만 선택했습니다. 간격 2 m의 해저 격자는 인과적으로 얻은
DVL 평면 평균에서 시작합니다. 외삽 영역은 측정된 해저가 아닌 사전 형상입니다.
DVL 거리 분산은 미확정이며 해상도나 분산 0으로 대체하지 않습니다.
공유 꼭짓점은 339개, 불투명 삼각형은 600개입니다. 삼각형별 반사율은 .001로
고정하고 각 시점에는 하나의 양수 공통 밝기 배율을 추정합니다.

`sonar_scene_fit.SceneHeightFit`는 공통 세계 좌표의 꼭짓점 높이를 바꿉니다.
법선을 고정한 거리 미분으로 이동 방향을 제안한 뒤, 모든 제안에서 실제 첫
교차점·float32 거리 기반 법선·Fourier 전력 평균을 다시 계산해 채택합니다.
제안 미분은 법선·가림 변화나 정보 행렬을 제공하지 않습니다. 이웃 높이 변화
벌점 10/㎡는 명시적인 형상 사전 제약이며 센서 잡음이 아닙니다. 픽셀마다
배율을 추가하지 않고 모든 잔차를 남깁니다. 유한 격자 바깥은 미지 영역으로
유지하며 빈 공간으로 간주하지 않습니다.

## 결과와 한계

169.1초 동안 현재 상태 평가 9회, 이동 제안 17회 중 8회를 채택합니다.
마지막 다섯 이동 크기가 모두 실제 목적함수를 개선하지 못해 중단합니다.
학습 전력의 복합 점수는 **2026.942→1778.554**, 미사용 시점 점수는
**1458.748→1215.957**로 줄어듭니다. 최종 사전 형상 벌점은 0.606입니다.
여덟 시점의 전체 전력 공분산을 보존하며, 주변 점수를 픽셀 독립성으로
해석하지 않습니다.

물체 가설의 표면 RMSE는 **5.04→4.95 cm**입니다. 기존 진단 기준 10 cm를
넘는 표본은 두 경우 모두 160개 중 14개입니다. 전체 표면 RMSE는
**13.09→13.09 cm**로, 관측되지 않은 해저 사전 형상의 영향이 큽니다.
여덟 시점을 합쳐 해저 576면 중 186면, 물체 24면 중 12면에만 예측 광선이
닿습니다. 광선 수는 보정된 물리적 지지나 독립 랜드마크 수가 아닙니다.
81/88/90 시점에는 큰 잔차가 남고, 미사용 51번 시점은 나빠집니다.
추정 메시·표면 표본·자세 갱신을 네이티브 SLAM에 채택하지 않습니다.

실제 역추정은 실행됐지만 누락된 관측 지지 문제는 남습니다. 고정 항법,
거친 해저, 후보 대응, 반사율·가림 대안과 자세·지도 공통 불확실성이 미해결입니다.
다음에는 반사체 후보의 생성·지속성과 국소 관측 지지를 미사용 시점에서
검증하고, 이후 공통 불확실성과 실제 DVL 잠금 상실 시 효용을 확인해야 합니다.
큰 합성 메시나 좋은 영상 점수만으로 유용한 지도에 합격시키지 않습니다.

## 재현

NumPy·SciPy 진단 의존성을 갖춘 POSIM-SLAM 체크아웃에서 실행합니다.

```sh
python -m unittest discover -s tests -p test_sonar_scene_fit.py
python docs/diagnostics/sonar-partial-scene-fit-20261031/verify.py
```

검증기는 모든 최종 원본 전력·평균·전체 공분산·전체 형상 평가와 PLY를 다시
계산합니다. 보이는 꼭짓점을 1 mm 바꾸는 음성 대조군은 수치 연산 허용 범위를
초과합니다. 최적화 자체는 반복하지 않습니다. 새 적합은 비어 있는 디렉터리에
`protocol.json`·`run_fit.py`를 복사하고 공유 진단 경로를 `--records`로 지정한 뒤
먼저 `--prepare`로 준비합니다. `construction-seal.json`은 평가 전에 모든 추정
입출력을 고정합니다. 준비 중 사전 키 중복 오류는 `setup-failure.json`에 보존하며,
이 오류로 추정이나 원본 변경은 발생하지 않습니다. 보존된 SDK에는 선택형 cv2가
없어 인접 로컬 검사 59개는 통과하고 기존 세션 검사 하나의 가져오기는 실패합니다.
호스팅 CI는 선언된 연구 의존성을 설치합니다. SDK는 변경하지 않습니다.

코드와 기록은 Apache-2.0입니다. 새 제3자 의존성·음향 관측 모델·SDK·렌더러
실행·아티팩트 다운로드·서비스 재시작을 추가하지 않습니다.
