# Static visual-map correspondence / 시각 지도의 고정 특징 대응

Native feature IDs, reprojection residuals and joint position information are
conditional on the feature model. A persistent image track can follow suspended
matter or changing illumination. An ID can also outlive its original image
appearance. Small linearized uncertainty does not prove static physical identity.

Keep original image times, feature pixels, native IDs, retirement and archive
admission evidence when diagnosing these cases. Evaluate every retained map
vertex independently of estimator input. Do not classify points using simulator
truth inside the estimator or equate a renderer check with map acceptance.

[Measured particle attribution, world-space renderer controls and retained failed native map](../validation/particle-static-correspondence-20261028/README.md)
preserve these distinct scopes. The record includes complete PLY and matched
isometric RGB/PCL, without private WWW-POSIM source.
