# 원본 소나 영상의 조건부 유한 형상 적합

[English](README.md)

![같은 기록 카메라의 현장 RGB와 초기·적합 형상의 전체 점](full-cloud-comparison.png)

기존 소스 법선·Fourier 관측 모델로 실제 기록 소나 전력에 형상을 맞춥니다.
인과적인 DVL 평면, 공통 평면, 해저에 놓인 불투명 직육면체 하나를 비교합니다.
직육면체는 제한적인 형상 가정이며, 표면에서 만든 점은 **관측된 랜드마크나
수용된 SLAM 지도가 아닙니다**. 항법은 고정하고 음향 측정으로 갱신하지 않습니다.

초기 형상에서 적합 형상으로 바꾸면 복합 평균 점수 합은 학습 시점 3개에서
**1086.626 → 1020.412**, 미사용 시간 시점 3개에서 **1167.244 → 1152.789**로
줄어듭니다. 같은 쿼리 안에서 낮을수록 좋지만 미터 오차나 보정된 우도비 통계는
아닙니다. 미사용 시점 중 2개는 개별 점수가 나빠집니다. 인과적·공통 해저 평면만
쓰면 학습 점수는 1557.475/1144.620, 미사용 점수는 1644.815/1557.370입니다.

각 형상에서 정해진 표면 점 **548개 전체**를 출력합니다. 가장 가까운 실제 표면에
대한 전체 RMSE는 **5.39 → 5.65 cm**, 진단용 10 cm 초과 수는 35 → 3입니다.
평가 물체 표면만을 기준으로 하면 RMSE는 **5.79 → 5.99 cm**, 최대 거리는
**11.52 → 12.80 cm**입니다. 큰 오차 수가 줄었다고 형상이 좋아졌다고 판정할 수는
없습니다. 영 오차나 보편적 해양 기준을 요구하는 시험이 아닙니다. 보이지 않은
뒷면까지 [초기](initial_prism-complete.ply)·[적합](fitted_prism-complete.ply) PLY에
모두 남깁니다. 벽과 해저는 지도화하지 못합니다.

## 입력과 사전 고정 절차

![원본 소나 영상 6개와 고정 쿼리](raw-sonar-queries.png)

[절차](protocol.json)는 적합 전에 고정했습니다. 정해진 인덱스 구간 3개에서
밝음·그림자·회복 후보가 가장 많은 49/88/151 프레임을 고르고, 두 프레임 뒤인
51/90/153을 시간 비교에 씁니다. 이미 조사한 개발 기록이므로 독립 장면 검증이
아닙니다. 각 프레임의 599×256 원본 배열 전체와 해시를 보존합니다. 학습 초기
형상의 투영 범위와 넓은 해저 대조 영역에서 프레임당 48픽셀을 고정합니다.
거리 축은 아래가 가깝고 위가 멉니다.

센서에서 구한 항법·인과적 DVL 평면 평균·학습 시점의 각도 중앙값 그림자 후보만
초기화에 씁니다. XY 군집 2개와 후보 73개를 모두 보존하고 가장 큰 군집으로
직육면체 하나를 시작합니다. 장면 메시·정답 자세·RGB·물체 실제 크기·평가된 점
배열은 초기화에 넣지 않습니다. 결과와 해시를 봉인한 뒤 별도로 평가했습니다.

제한된 좌표 탐색은 후보마다 첫 교차면·소스의 거리 기반 법선·정확한 유한 Fourier
평균을 다시 계산합니다. 평면 3변수, 물체 위치·크기·높이·회전과 물체/해저 반사율
비를 맞춥니다. 시점마다 양수 공통 밝기 이득 하나를 추정하며 픽셀별 이득은
허용하지 않습니다. 최종 반사율 비는 2.718입니다. 탐색 범위는 계산 선택이며
보정된 불확실성이나 관측된 물체 범위를 뜻하지 않습니다. 모든 채택·기각 단계와
불가 사례를 기록합니다. 이 호스트에서 평가 110회에 301초가 걸린 오프라인
개발 시험이며 운영 속도를 주장하지 않습니다.

작은 묶음으로 계산한 정확한 평균은 모든 최종 상태에서 기존 전체 복소 공분산
연산과 일치합니다. 선택한 원본 전력·평균·전체 상관 공분산을 보존합니다. 지수
주변분포의 복합 점수를 맞춘다고 픽셀이 독립이 되지는 않습니다. 자세·평면의
불확실성, 시점 사이의 공통 항법 오차, 다른 물체·재질, 미지의 범위와 가림의
모호성은 이 조건부 적합에서 제외됩니다. 기여 전력이 작아도 형상과 점은 남깁니다.

공통 평면이 모델 오차를 대신 흡수할 수 있어 영상 점수만으로 형상을 수용하지
않습니다. 제한된 탐색이 전역 최적해나 음향 렌더링 방법 자체의 실패를 입증하지도
않습니다. 다음에는 보존된 탐색 기록과 영상 잔차 영역으로 형상·재질·해저의 혼동과
관측되지 않는 방향을 조사한 뒤 표면 모델이나 네이티브 제약을 선택해야 합니다.
결합 불확실성·독립 장면·실제 DVL 손실/부재 때의 항법 개선은 여전히 수용 조건입니다.
이 표면 점을 독립적인 고정 XYZ 측정으로 바꾸지 않습니다.

## 소스와 재현

[현재 #6/#31–36 커밋](source-pr-heads.json)은 모두 별도 POSIM 통합 **ffecee9b**에
들어 있으며 PR 자체는 열려 있고 미병합입니다. 15 m·거리 599빈·256빔·수직 광선
256개를 사용합니다. 기록의 조사용 장착각은 아래 35°이며 제품 기본값을 바꾸지
않습니다. IMU·수압·DVL은 원본 스트림이고 Ping은 없습니다. SDK·네이티브 제약·
센서 물리·잡음·신선도·지도 수용 기준은 바꾸지 않습니다.

비교 그림은 기록된 같은 등각 RGB 카메라 투영과 잘라낸 범위, 64 pt² 점 크기와
전체 높이의 파랑→빨강 Turbo 범위를 공유합니다. RGB와 회색 장면 윤곽은 평가용입니다.
현장 확인용 RGB만 안개·흡수를 끄고 조명·해저 집광무늬·입자·파도는 다른 위상으로
남깁니다. 실제 추정 카메라는 가시거리 2 m를 유지합니다. 주황은 소나/동일 장착
RGB 방향, 파랑은 기체 RGB 방향, 검정은 기체 위치입니다. 저장 공간 기준 아래에서
새 현장·렌더러 시험을 실행하지 않았습니다.

공개 라이브러리의 `research,diagnostics` 의존성으로 실행합니다.

```sh
python docs/diagnostics/sonar-finite-geometry-fit-20261031/verify.py
```

검증기는 원본 해시·구성 봉인·소스 식별·모든 최종 상관 모멘트와 점수·전체 표면
점·PLY·별도 평가를 다시 확인합니다. 소스 법선 전력 재현 허용치는 이전 네이티브
전력 대조군과 같은 상대 2e-7이며 지도 잡음이나 수용 기준이 아닙니다. 앞선 공개
기록의 현장 RGB·장면을 참조해 큰 원본을 중복 저장하지 않습니다.

`fit.py prepare`에 `--records`(진단 기록 상위 폴더)와 `--raw`(원본 입력 폴더)를
주고 `fit.py fit`으로 고정 절차를 실행합니다. 생성기와 절차가 있는 새 출력 폴더가
필요하며 기존 탐색 기록을 덮어쓰지 못하게 합니다. `assess.py`·`render.py`는
`--records`를 받고 봉인 이후에 실행합니다. 일반 출력의 `causal_plane_triangles`는
쓰이지 않는 초기 평면 자리표시자입니다. 실제 시점별 인과적 평면은 `inputs.json`에서
따로 복원하며 공통 적합 평면과 구분합니다.

유한 광선 렌더링·형상 사전 가정·재질 이득 추정·좌표 탐색은 기존 요소이며 연구
신규성을 주장하지 않습니다. 공개 NumPy/SciPy 구현은 WWW-POSIM 코드를 가져오지
않습니다. 기존 구성요소·제삼자 고지와 라이선스는 유지합니다.
