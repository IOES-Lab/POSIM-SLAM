# 조건부 소나 그림자 기하

[English](README.md)

[45° 검사 기록](../sonar-close-view-20261031/README.ko.md)의 원본 150프레임을 재사용한 오프라인 비교입니다. POSIM 통합 소스는 `ffecee9b`이며 현재 PR #6·#31–36을 포함합니다. 두 방식 모두 IMU·DVL·압력 기반의 같은 미지 바이어스 추정 자세 223개를 사용합니다. RGB·지형 메시·시뮬레이터 정답 자세는 복원에 넣지 않습니다. 네이티브 제약식, 설치 SDK, 제품 기본값과 지도 승인 규칙은 그대로입니다.

## 관측 모델

DVL의 바닥 잠금 빔 네 개로 국소 평면을 맞춥니다. 각 빔의 2° 원뿔 안에서 가장 가까운 거리를 사용하며, 자세가 있는 패킷은 74개입니다. 거리 분산은 알려져 있지 않습니다. 소나 프레임은 최대 1.01초 이전의 패킷만 사용합니다. 이 평면을 DVL 관측 면적 밖으로 연장하므로, 바닥 굴곡이나 더 가까운 물체가 가정을 깨뜨릴 수 있습니다. 시작 프레임 세 개는 사용 가능한 과거 자세·평면이 없으며 원본을 보존합니다.

대조군은 주어진 평면과 소나 수직 시야가 만나는 시작·끝 거리를 정렬한 뒤 각도 방향 중앙값을 뺍니다. 물리 모델 방식은 기존 `SurfacePowerModel`로 균일한 평면의 밝기를 예측합니다. 거리 감쇠·입사각, 256 × 256 광선, Hamming 거리 응답과 빔 혼합을 반영합니다. 프레임마다 공통 로그 파워 이득 하나만 맞추며 물체 형상은 주지 않습니다. 두 방식에 같은 5표본 중앙값 필터, 경험적 8dB 어두움 기준과 영역 규칙을 적용합니다. 낮은 반사율도 어두움을 만들 수 있으므로 오경보 확률이 보정된 검출기는 아닙니다.

실제 가림 경계와 그 그림자의 바닥 끝이 같은 광선 위에 있다면 `높이 = H × (1 − r_edge/r_end)`입니다. `H`는 센서와 평면 사이의 수직 거리입니다. 주어진 평면과 그림자 끝 거리로 고도각이 하나로 정해질 때만 점을 계산합니다. 해가 둘이거나 접선·교점 없음·시야 잘림이면 미결로 남깁니다. 어두운 영역의 경계를 실제 가림 경계로 보는 것은 가정입니다. 임계값·필터의 편향, 잘못된 짝과 평면 오차는 이 국소 계산에 포함되지 않습니다.

물체와 그림자를 이용한 복원은 [Song·Choi, 2016](https://oak.go.kr/central/journallist/journaldetail.do?article_seq=20801)의 기존 연구 주제입니다. 여기서는 기본적인 일직선 기하와 기존 소스별 파워 연산자를 독립적으로 구현했습니다. 논문의 코드·문장·그림을 복사하지 않았으며, 논문의 전체 반사율·고도 복원 방법을 구현하거나 새 연구 성과를 주장하는 기록은 아닙니다.

## 보존한 전체 결과

아래 점은 서로 상관된 **관측 가설**입니다. 고유 랜드마크나 승인된 지도점의 수가 아닙니다. 큰 오차를 포함한 모든 출력과 전체 PLY를 보존합니다. 앞쪽 0.15m 안에서 배경보다 3dB 이상 밝은 반사가 있고 뒤쪽 0.15m 안에서 배경의 3dB 이내로 돌아오면 ‘짝 관측’으로 표시합니다. 이 역시 경험적 진단 표시이며 다른 출력도 모두 남깁니다.

| 동일 입력 결과 | 각도 중앙값 대조군 | 물리 평면 배경 |
| --- | ---: | ---: |
| 보존한 영역 후보 | 1,007 | 675 |
| 잘린 영역 / 닫힌 영역 | 542 / 465 | 578 / 97 |
| 전체 조건부 점 | 3,911 | 1,428 |
| 전체 표면 오차 RMSE | 0.0553m | 0.0970m |
| 10cm를 넘는 전체 점 | 319 / 3,911 | 286 / 1,428 |
| 짝 관측 부분집합 | 547 | 325 |
| 짝 관측 표면 오차 RMSE | 0.0324m | 0.0259m |
| 10cm를 넘는 짝 관측 | 9 / 547 | 5 / 325 |

물리 배경은 작은 어두운 후보를 많이 줄이지만, 전체 출력의 RMSE는 더 큽니다. 출력의 구성도 달라지므로 전체 RMSE나 더 나은 짝 관측 결과만으로 지도 개선을 입증할 수 없습니다. 물리 모델의 짝 관측 325개 중 320개가 첫 블록에서 10cm 이내에 있습니다. 다른 블록 두 개와 벽의 지도 범위를 확보한 결과는 아닙니다. 큰 오차 다섯 개도 보존합니다.

![실제 네이티브 현장과 모든 조건부 관측](full-cloud-comparison.png)

점군은 같은 등각 방향, 전체 Turbo 높이 범위, 64pt² 마커를 사용합니다. 현장 RGB는 실제 28.01초 자세에서 네이티브로 다시 렌더링한 평가용 영상입니다. 형상을 보기 위해 안개·흡수만 끄고 파도·조명·입자·해저 집광무늬는 유지합니다. 차량과 카메라·소나 방향을 표시합니다. 원본 센서 RGB는 가시거리 2m를 유지하며 복원 입력이 아닙니다. [원본 RGB·소나 비교](../sonar-close-view-20261031/sensor-comparison.png).

![원본 소나와 물리 배경 대비 잔차](shadow-observations.png)

고정한 세 예시는 원본 15m 거리 중 0–6m를 확대한 것으로, 가까운 곳이 아래이며 축은 미터입니다. 대표 NPZ마다 원본 599 × 256 셀 전체를 유지합니다. 잔차 색과 윤곽은 어두운 후보를 뜻하며 물체 정답이나 빈 공간을 뜻하지 않습니다. 16.50초는 근접 검사 이전이고 나머지는 28.01초와 41.51초입니다.

## 지속성과 한계

전체 150프레임 중 21개에서 물리 모델의 짝 관측이 하나 이상 나옵니다. 프레임·영역 20개에 관측이 세 개 이상 있습니다. 사후 시간 분할에서 처음 열 개의 높이 중앙값 0.41336m를 계산하고, 최소 2초 뒤의 나머지 열 개는 반복성 확인에만 씁니다. 높이 차이 RMSE는 4.50mm입니다. 이는 **반복성**이며 절대 정확도가 아닙니다. 실제로 만든 블록 높이는 0.45m이고 추정 DVL 평면은 다른 불확실한 기준면입니다.

이 20개 관측에서 학습 구간 중심을 바라보는 방위 변화는 3.97°뿐이며, 소나 원점의 축별 이동 폭은 0.148 / 0.119 / 0.0258m입니다. 차량의 큰 제자리 회전이 넓은 독립 시점을 만들지는 않습니다. 가림 윤곽은 시점에 따라 바뀌므로 고정 XYZ 랜드마크로 넣을 수 없습니다. 공유 자세·평면 불확실성, 평면 연장, 대응과 임계값 편향이 남습니다. 네이티브 자세 보정·항법 개선·지도 승인·설치형 앱 합격은 주장하지 않습니다.

`shadow_edge()`는 명시적인 전체 상관 공분산을 받을 수 있습니다. 이 기록에는 DVL 거리 불확실성 모델이 없어 점의 3시그마를 만들어 넣지 않습니다. 독립 대조 검사는 가림의 순방향 기하, 미분, 상관 오차, 다중 해·접선, 이득·스케일 불변성, 시야 극값, 연결 영역과 유효한 무반사를 확인합니다.

## 재현

POSIM-SLAM 소스에서 `pip install -e '.[diagnostics]'` 후 실행합니다.

```sh
python docs/diagnostics/sonar-shadow-support-20261031/test_shadow_geometry.py
python docs/diagnostics/sonar-shadow-support-20261031/test_shadow_extract.py
python docs/diagnostics/sonar-shadow-support-20261031/verify.py
```

검증기는 지원되는 DVL 평면 74개를 다시 맞추고 과거 입력만 사용했는지 확인합니다. 조건부 출력 5,339개와 전체 PLY, 모든 표면 평가, 좁은 시점에서의 높이 분할 결과를 재현합니다. 원본 영상 추출 재현은 전체 대표 프레임 세 개를 대상으로 하며 나머지 원본 해시와 파생 후보 목록도 보존합니다. 전체 원본 영상·네이티브 수집·센서 보정을 다시 실행하는 검사는 아닙니다. 전체 원본은 외장 디스크의 기준 기록 한 곳에 유지합니다. `plot_comparison.py`와 `plot_observations.py`로 그림을 다시 그립니다. 공유한 Orca5 유래 장면·RGB는 연결한 기록의 [MIT 고지](../sonar-inspection-scene-20261031/Orca5-LICENSE.txt)를 유지합니다.

다음에는 공유 가림·바닥면 관측에 결합 불확실성과 실제 병진 시점 변화를 적용합니다. 이전 표면·structureless 실패를 검토하고 그림자 경계를 또 다른 고정점 제약식으로 바꾸지 않습니다. 실제 DVL 손실·부재, 초기화, 센서 조합, 플랫폼, VRX와 후속 WAM-V 측량 검증은 남아 있습니다.
